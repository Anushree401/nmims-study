1. In-Depth Theory & Lecture Explanation

1.1 Otsu's Optimal Global Thresholding Algorithm

Developed by Nobuyuki Otsu in 1979, this statistical clustering algorithm automatically finds the optimal threshold \(k^*\) that partitions image pixels into two classes: \(C_1\) (background: \([0, k]\)) and \(C_2\) (foreground: \([k+1, L-1]\)).

Otsu's Core Criterion: Maximizing Between-Class Variance

Otsu proved that minimizing intra-class variance is mathematically equivalent to maximizing between-class variance \(\sigma_B^2(k)\):

$$\mathbf{\sigma_B^2(k) = P_1(k) [m_1(k) - m_G]^2 + P_2(k) [m_2(k) - m_G]^2 = \frac{[m_G P_1(k) - m(k)]^2}{P_1(k)[1 - P_1(k)]}}$$

where:

  • \(P_1(k) = \sum_{i=0}^k p_i\) (Cumulative probability of Class 1)
  • \(m(k) = \sum_{i=0}^k i \cdot p_i\) (Cumulative mean of Class 1)
  • \(m_G = \sum_{i=0}^{L-1} i \cdot p_i\) (Global mean of the entire image)
  • \(k^* = \arg\max_{0 \le k < L-1} \sigma_B^2(k)\) (Optimal threshold).

1.2 Region-Based Segmentation: Growing vs. Splitting & Merging

  • Region Growing: Starts with an initial set of "seed points" and appends neighboring pixels to the region if they satisfy a predefined similarity predicate (e.g., \(|f(x, y) - \text{seed}| \le T\)).
    Stopping Rule: Growth halts when no neighboring pixels satisfy the predicate.
  • Region Splitting and Merging (Quadtree Algorithm): Subdivides an image into quadrants iteratively:
    1. If region \(R_i\) is inhomogeneous (predicate \(Q(R_i) = \text{False}\)), split \(R_i\) into 4 equal subquadrants.
    2. When no more splits are possible, merge adjacent regions \(R_j\) and \(R_k\) if their union is homogeneous: \(Q(R_j \cup R_k) = \text{True}\).

1.3 Bayesian Foreground/Background Classification

For an observed pixel feature or intensity (x), Bayesian classification compares the posterior probabilities of foreground (F) and background (B):

\[P(F\mid x)= rac{P(x\mid F)P(F)}{P(x)},\qquad P(B\mid x)= rac{P(x\mid B)P(B)}{P(x)}.\]

Assign the pixel to the class with the larger posterior probability. Since (P(x)) is common to both classes, compare (P(x\mid F)P(F)) with (P(x\mid B)P(B)). The likelihoods model class-specific pixel values and the priors encode prior class prevalence. The decision depends on those assumptions and is not automatically the same as Otsu's global threshold.

For pixel adjacency and 4-, 8-, and m-connectivity definitions, review Unit 1 pixel relationships.

Problem 6.1: Step-by-Step Otsu Thresholding Calculation

Problem Statement (From NMIMS Paper 1 Q5): Consider an image with 6 gray levels \([0, 5]\) and normalized histogram: $$p_0 = 0.1, \quad p_1 = 0.4, \quad p_2 = 0.3, \quad p_3 = 0.1, \quad p_4 = 0.05, \quad p_5 = 0.05$$ Find the optimal threshold using Otsu's method for threshold values \(k = 1\) and \(k = 2\) only.

GLOBAL MEAN
$$m_G = \sum_{i=0}^5 i \cdot p_i = (0\cdot 0.1) + (1\cdot 0.4) + (2\cdot 0.3) + (3\cdot 0.1) + (4\cdot 0.05) + (5\cdot 0.05)$$ $$m_G = 0 + 0.4 + 0.6 + 0.3 + 0.2 + 0.25 = \mathbf{1.75}$$
THRESHOLD k = 1

\(P_1(1) = p_0 + p_1 = 0.1 + 0.4 = \mathbf{0.50}\). \(P_2(1) = 1 - 0.50 = \mathbf{0.50}\).
\(m(1) = (0\cdot 0.1) + (1\cdot 0.4) = \mathbf{0.40}\).
Class 1 Mean: \(m_1 = \frac{0.40}{0.50} = \mathbf{0.80}\).
Class 2 Mean: \(m_2 = \frac{m_G - m(1)}{1 - P_1} = \frac{1.75 - 0.40}{0.50} = \frac{1.35}{0.50} = \mathbf{2.70}\).
Between-class variance:

$$\sigma_B^2(1) = P_1 P_2 (m_1 - m_2)^2 = (0.50)(0.50)(0.80 - 2.70)^2 = 0.25 \times (-1.90)^2 = 0.25 \times 3.61 = \mathbf{0.9025}$$
THRESHOLD k = 2

\(P_1(2) = 0.1 + 0.4 + 0.3 = \mathbf{0.80}\). \(P_2(2) = 1 - 0.80 = \mathbf{0.20}\).
\(m(2) = 0.40 + (2\cdot 0.3) = 0.40 + 0.60 = \mathbf{1.00}\).
Class 1 Mean: \(m_1 = \frac{1.00}{0.80} = \mathbf{1.25}\).
Class 2 Mean: \(m_2 = \frac{1.75 - 1.00}{0.20} = \frac{0.75}{0.20} = \mathbf{3.75}\).
Between-class variance:

$$\sigma_B^2(2) = (0.80)(0.20)(1.25 - 3.75)^2 = 0.16 \times (-2.50)^2 = 0.16 \times 6.25 = \mathbf{1.0000}$$
CONCLUSION

\(\sigma_B^2(k=1) = \mathbf{0.9025} \quad | \quad \sigma_B^2(k=2) = \mathbf{1.0000}\)

Since \(\sigma_B^2(2) > \sigma_B^2(1)\), threshold \(k = 2\) provides superior separation between foreground and background.

Core Exam Takeaways:

  • Otsu Criterion: Maximizes between-class variance: \(\sigma_B^2(k) = P_1 P_2 (m_1 - m_2)^2\).
  • Quadtree Rules: Split if false; Merge if true.
  • Component Labeling: Resolves foreground connected components into unique integer IDs.
