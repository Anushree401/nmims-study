1.1 Representation of Digital Image: Image as a Function & Matrix

In physical optics, an image is a 2D projection of a 3D scene. Mathematically, a monochrome continuous image is represented by a two-dimensional spatial intensity function:

$$\mathbf{f(x, y)}$$

where \(x\) and \(y\) are spatial (plane) coordinates, and the amplitude \(f\) at any coordinate pair \((x, y)\) is called the intensity or gray level of the image at that point.

Physical Illumination and Reflectance Model

The intensity function \(f(x, y)\) is physically characterized by two fundamental components:

$$\mathbf{f(x, y) = i(x, y) \cdot r(x, y)}$$
  • Illumination \(i(x, y)\): The amount of source incident light energy falling onto the physical object being viewed. Physical bounds: \(0 < i(x, y) < \infty\) (measured in lumens/\(\text{m}^2\)).
  • Reflectance \(r(x, y)\): The fraction of incident light reflected back from the object's surface into the camera sensor. Physical bounds: \(0 \le r(x, y) \le 1\) (where \(0 = \text{total absorption / pure black}\), and \(1 = \text{total reflection / pure white}\)).

Matrix Representation of a Digital Image:

When coordinates \((x, y)\) and amplitude values \(f\) are all finite, discrete quantities, we call the image a Digital Image. A digital image with \(M\) rows and \(N\) columns is mathematically represented as an \(M \times N\) numerical matrix:

$$f(x, y) = \begin{bmatrix} f(0, 0) & f(0, 1) & \dots & f(0, N-1) \\ f(1, 0) & f(1, 1) & \dots & f(1, N-1) \\ \vdots & \vdots & \ddots & \vdots \\ f(M-1, 0) & f(M-1, 1) & \dots & f(M-1, N-1) \end{bmatrix}$$

Each individual element in this 2D array is referred to as an image element, picture element, pels, or universally as a Pixel.

1.2 Image Digitization: Sampling and Quantization

Physical sensors output continuous analog voltage signals. To transform continuous optical signals into digital matrix form requires two processes:

  • Sampling: Digitizing the continuous spatial coordinates \((x, y)\). The continuous 2D plane is partitioned into a discrete spatial grid of sampling points (pixels).
  • Quantization: Digitizing the continuous amplitude/intensity values \(f(x, y)\). Continuous voltage levels are mapped into discrete numerical integers called gray levels.

1.3 Spatial Resolution vs. Gray-Level (Intensity) Resolution

  • Spatial Resolution: A measure of the smallest discernible physical detail in an image. Quantitatively defined as the number of independent pixel samples per unit distance (e.g., dots per inch - DPI, pixels per millimeter, or line pairs per mm).
    Under-sampling artifact: If an image is under-sampled (insufficient spatial samples), fine details vanish and Checkerboarding / Pixelation occurs.
  • Gray-Level (Intensity) Resolution: Refers to the smallest discernible change in gray level/intensity. The number of discrete gray levels \(L\) is typically an integer power of 2: $$\mathbf{L = 2^k}$$ where \(k\) is the bit depth (e.g., \(k = 8\text{ bits} \implies L = 256\text{ gray levels}\), from 0 to 255).
    Under-quantization artifact: When an image is quantized with too few bits (e.g., \(k \le 4\)), continuous smooth gradations break into visible abrupt artificial bands. This visual flaw is called False Contouring.

1.4 Basic Relationships Between Pixels: Neighborhoods

Consider a central pixel \(p\) located at spatial coordinate \((x, y)\):

Figure 1.2: 4-Neighbors \(N_4(p)\) in blue vs. Diagonal Neighbors \(N_D(p)\) in yellow.

  • 4-Neighbors of \(p\) (\(N_4(p)\)): The four horizontal and vertical orthogonal neighbors: $$N_4(p) = \{(x+1, y), (x-1, y), (x, y+1), (x, y-1)\}$$
  • Diagonal Neighbors of \(p\) (\(N_D(p)\)): The four corner diagonal neighbors: $$N_D(p) = \{(x+1, y+1), (x+1, y-1), (x-1, y+1), (x-1, y-1)\}$$
  • 8-Neighbors of \(p\) (\(N_8(p)\)): The union of 4-neighbors and diagonal neighbors: $$N_8(p) = N_4(p) \cup N_D(p)$$

1.5 Pixel Connectivity: 4-Connectivity, 8-Connectivity & m-Connectivity

To establish boundaries, regions, and object contours, pixels must be connected. Two pixels \(p\) and \(q\) are connected if they are spatial neighbors AND their intensity values both satisfy a specified set of similarity values \(V\) (e.g., \(V = \{1\}\) for binary images, or \(V = \{128, 129, \dots, 255\}\) for gray-scale):

  1. 4-Connectivity: Two pixels \(p\) and \(q\) with values from \(V\) are 4-connected if \(q \in N_4(p)\).
  2. 8-Connectivity: Two pixels \(p\) and \(q\) with values from \(V\) are 8-connected if \(q \in N_8(p)\).
  3. m-Connectivity (Mixed Connectivity): Solves the Ambiguity of Multiple Paths inherent in 8-connectivity! Two pixels \(p\) and \(q\) with values from \(V\) are m-connected if:
    (a) \(q \in N_4(p)\), OR
    (b) \(q \in N_D(p)\) AND the intersection set \(N_4(p) \cap N_4(q)\) contains no pixels with values from \(V\)!

Exam Crucial Rule on m-Connectivity:

m-Connectivity eliminates redundant diagonal jumps. If a diagonal neighbor can be reached via a shared 4-neighbor that also has a value from \(V\), the direct diagonal connection is strictly forbidden!

1.6 Distance Metrics: Euclidean, City-Block & Chessboard

For mathematical distance function \(D\) to be a true metric between pixels \(p(x, y)\), \(q(s, t)\), and \(z(u, v)\), it must satisfy four properties:
(1) \(D(p, q) \ge 0\), (2) \(D(p, q) = 0 \iff p = q\), (3) \(D(p, q) = D(q, p)\) (Symmetry), (4) \(D(p, z) \le D(p, q) + D(q, z)\) (Triangle Inequality).

The Three Fundamental Distance Metrics:

Metric Formula Geometric Iso-Distance Contour Shape
Euclidean Distance (\(D_e\)) $$D_e(p, q) = \sqrt{(x - s)^2 + (y - t)^2}$$ Concentric Circles of radius \(r\).
City-Block Distance (\(D_4\)) $$D_4(p, q) = |x - s| + |y - t|$$ Diamond / Rhombus oriented at 45° (Manhattan grid walking).
Chessboard Distance (\(D_8\)) $$D_8(p, q) = \max(|x - s|, |y - t|)$$ Concentric Squares with horizontal/vertical sides (King's move in chess).

1.7 Image File Formats: JPEG vs. PNG vs. TIFF (From NMIMS Paper 1)

Feature / Parameter JPEG (Joint Photographic Experts Group) PNG (Portable Network Graphics) TIFF (Tagged Image File Format)
Compression Type Lossy (based on Discrete Cosine Transform - DCT). High compression ratio. Lossless (Deflate / LZ77 predictive compression). Preserves exact pixels. Supports Lossless (LZW), Lossy, or Uncompressed data streams.
Bit Depth Standard 8-bit per channel (24-bit TrueColor). 8-bit indexed up to 16-bit per channel (48-bit TrueColor). 8-bit, 16-bit, 32-bit floating point HDR per channel.
Transparency Support No transparency support (background defaults to white). Full Alpha Channel Transparency (8-bit semi-transparency). Full Alpha Channel Transparency support.
Primary Application Final distribution of continuous-tone photographs and web graphics. Editing graphics, screenshots, logos, medical diagrams with sharp text. Professional desktop publishing, raw scanner outputs, medical archival.

1.8 Colour Image Basics

A colour image stores a vector of component values at each pixel rather than a single gray-level intensity. In the common additive RGB representation, each pixel is ((R,G,B)); the channels combine to represent colour, and channel bit depth determines the number of representable values. A colour image can also be processed as separate component planes.

The exact numeric range depends on representation (for example, normalized values or 8-bit channel values). Do not confuse colour depth with spatial resolution: spatial resolution counts pixel locations; colour depth describes the values stored per pixel.

2. In-Depth Metric Numericals

Step-by-Step Solved Calculations
Storage Capacity Calculation

Problem 1.1: Uncompressed Image Storage Requirements

Problem Statement: Calculate the uncompressed image storage. Use binary units for the worked values: 1 MiB = 1024² bytes (often called MB in course questions).
(a) An \(8\text{-bit}\) grayscale image of dimensions \(2048 \times 2048\) pixels.
(b) A \(24\text{-bit}\) TrueColor RGB image of dimensions \(1920 \times 1080\) (Full HD).

Assumption: Storage is uncompressed and excludes file headers, metadata, row padding, and audio. If the exam defines MB as decimal, divide by 1,000,000; the values above use MiB (1,048,576 bytes).

FORMULA
$$\mathbf{\text{Storage Size (Bytes)} = \frac{M \times N \times k}{8}} \qquad \mathbf{\text{Size in MiB} = \frac{\text{Bytes}}{1024 \times 1024}}$$
CALCULATIONS

Part (a): Grayscale \(2048 \times 2048\) with \(k = 8\text{ bits}\):

$$\text{Bytes} = 2048 \times 2048 \times 1\text{ byte} = 4,194,304\text{ bytes}$$ $$\text{Size (MiB)} = \frac{4,194,304}{1024 \times 1024} = \mathbf{4.00\text{ MiB}}$$

Part (b): TrueColor \(1920 \times 1080\) with \(k = 24\text{ bits} = 3\text{ bytes}\):

$$\text{Bytes} = 1920 \times 1080 \times 3\text{ bytes} = 6,220,800\text{ bytes}$$ $$\text{Size (MiB)} = \frac{6,220,800}{1024 \times 1024} \approx \mathbf{5.93\text{ MiB}}$$
FINAL RESULT

\(\text{Grayscale } (2048 \times 2048): \mathbf{4.00\text{ MiB}} \quad | \quad \text{Full HD RGB } (1920 \times 1080): \mathbf{5.93\text{ MiB}}\)

Distance Metrics Trace

Problem 1.2: Euclidean, City-Block, Chessboard & Shortest m-Path Trace

Problem Statement: Consider pixels \(p(1, 1)\) and \(q(4, 5)\).
(a) Compute \(D_e(p, q)\), \(D_4(p, q)\), and \(D_8(p, q)\).
(b) In a binary image region, trace the shortest m-path between \((0, 0)\) and \((2, 2)\) for \(V = \{1\}\) in grid:

1 (p)   1       0
0       1       1
0       0       1 (q)
PART (a) METRICS
  • \(D_e = \sqrt{(1 - 4)^2 + (1 - 5)^2} = \sqrt{(-3)^2 + (-4)^2} = \sqrt{9 + 16} = \sqrt{25} = \mathbf{5.00}\)
  • \(D_4 = |1 - 4| + |1 - 5| = 3 + 4 = \mathbf{7}\)
  • \(D_8 = \max(|1 - 4|, |1 - 5|) = \max(3, 4) = \mathbf{4}\)
PART (b) m-PATH

Start at \(p(0, 0) = 1\).
Neighbor \((0, 1) = 1\) is in \(N_4(p)\) \(\to\) Path: \((0, 0) \to (0, 1)\).
From \((0, 1)\), neighbor \((1, 1) = 1\) is in \(N_4(0, 1)\) \(\to\) Path: \((0, 1) \to (1, 1)\).
From \((1, 1)\), neighbor \((1, 2) = 1\) is in \(N_4(1, 1)\) \(\to\) Path: \((1, 1) \to (1, 2)\).
From \((1, 2)\), destination \(q(2, 2) = 1\) is in \(N_4(1, 2)\) \(\to\) Path: \((1, 2) \to (2, 2)\).
Can we take diagonal jump \((1, 1) \to (2, 2)\)?
Check intersection: \(N_4(1, 1) \cap N_4(2, 2)\) contains pixel \((1, 2)\). Since pixel \((1, 2)\) has value \(1 \in V\), direct diagonal jump is FORBIDDEN by m-connectivity rule!
Thus shortest m-path has length: \(\mathbf{4\text{ steps}}\).

3. Comprehensive Comparative Studies

Frequent Exam Distinctions

Table 1.1: 4-Connectivity vs. 8-Connectivity vs. m-Connectivity

Dimension 4-Connectivity 8-Connectivity m-Connectivity
Allowed Neighbor Types Horizontal and Vertical orthogonal neighbors only (\(N_4\)). Horizontal, Vertical, and Diagonal neighbors (\(N_8\)). 4-neighbors, or diagonal neighbors if no shared 4-neighbor belongs to \(V\).
Path Ambiguity Zero diagonal paths; can disconnect diagonal boundaries. Severe Ambiguity: Allows multiple redundant paths through a \(2 \times 2\) block. Zero Ambiguity: Mathematically eliminates redundant diagonal pathways.
Shortest Path Length Longest path length (constrained to Manhattan grid). Shortest path length (allows diagonal shortcuts). Intermediate path length (consistent topological boundaries).

4. Real-World Sensor Technologies

Physical Imaging Systems
Camera Sensor Case Study

CCD vs. CMOS Image Sensors

  • CCD (Charge-Coupled Device): Converts light into electrical charges across photo-sites, shifting analog charges sequentially down columns into a single central amplifier. Delivers outstanding dynamic range and low noise; high power consumption.
  • CMOS (Complementary Metal-Oxide Semiconductor): Each individual pixel contains its own integrated amplifier and analog-to-digital converter. Extremely low power, high readout speed (used in modern smartphones and high-speed video).
