1. CSP model and constraint types

  • A constraint satisfaction problem is (X,D,C): variables X, domains D of allowed values, and constraints C that specify allowed combinations.
  • A solution is a complete assignment satisfying every constraint.
  • Partial assignments are consistent if no constraint is violated.
  • Constraint graph: variables are nodes; binary constraints are edges.

2. Backtracking search

  • Backtracking is depth-first search assigning one variable at a time.
  • At each step choose an unassigned variable, try a domain value consistent with assigned neighbors, recurse; if no value works, undo the last choice.
  • Assignments commute, so search need not represent every ordering of the same assignment set.
  1. Select variable and value.
  2. Check constraints against current partial assignment.
  3. If consistent, continue.
  4. If failure, undo and try another value.
  5. Success when all variables assigned consistently.
  • Worst-case exponential, roughly O(dn) for n variables and domain size d, but heuristics and propagation cut the explored tree substantially.

3. Variable/value ordering heuristics

  • MRV (minimum remaining values): choose the unassigned variable with the fewest legal values; exposes failure early.
  • Degree heuristic: break ties by choosing the variable constraining the most unassigned neighbors.
  • LCV (least constraining value): try the value that rules out the fewest choices for neighbors first.

Worked map-coloring trace

  • Australia variables WA, NT, SA, Q, NSW, V, T; each domain {R,G,B}; adjacent regions differ.
  1. Choose SA first by degree: it touches WA, NT, Q, NSW, V.
  2. Assign SA=R. Neighbors lose R, domains become {G,B}; Tasmania T remains {R,G,B}.
  3. Choose a neighbor, e.g. NT, then MRV ties; use degree to prioritize WA/Q/NSW as appropriate.
  4. Assign NT=G; WA and Q cannot be G or R (adjacent to SA), so WA= B and Q=B are forced if their remaining domains shrink to one.
  5. Check Q–NSW: because both cannot be B, set NSW=G; then V adjacent to SA and NSW must be B.
  6. Final assignment is valid if every edge has different colors; backtrack immediately if a domain empties.

4. Constraint propagation: forward checking and arc consistency

  • Forward checking after assigning X=v removes inconsistent values from each unassigned neighbor’s domain.
  • If any becomes empty, fail early.
  • It does not propagate through chains beyond direct neighbors.
  • Arc consistency: directed arc X→Y is consistent if for every value x in D(X), there is some y in D(Y) satisfying constraint(X,Y).
  • Revise removes unsupported x values; enqueue affected neighboring arcs and repeat until no changes or a domain empties (AC-3 pattern).
  • Stronger propagation than forward checking, but costs more.
  • Deck’s example: assigning WA=R removes R from neighbors.
  • Later assigning NT=G constrains SA, Q, NSW and V; propagation can force values before those variables are selected.

5. Intelligent backtracking

  • Chronological backtracking returns to the immediately preceding variable, even if it did not cause the failure.
  • Backjumping records a conflict set of prior variables that constrain the failed variable and jumps to the most recent variable in that set.
  • In the slide example, failure at SA depends on {Q, NSW, V}; changing Tasmania cannot help, so skip it and backtrack to V.
  • Conflict-directed methods avoid repeating irrelevant choices.

Lesson A · Why constraint satisfaction is a special kind of search

  • Many problems are not about finding any path through states; they are about assigning values while obeying restrictions.
  • A timetable assigns a time and room to every course.
  • Map coloring assigns a color to every region.
  • A cryptarithm assigns digits to letters.
  • In each case, a solution is a complete assignment with no violated constraint.
  • Write a CSP as variables X, domains D and constraints C.
  • A partial assignment is consistent if all constraints whose variables are assigned are satisfied.
  • A constraint graph is helpful: each variable is a node, each binary constraint is an edge.
  • Dense/high-degree variables restrict many neighbors, which is why degree ordering is useful.

Australia map model

  • Variables WA, NT, SA, Q, NSW, V, T.
  • Each mainland region has domain {R,G,B}; T has the same domain but no adjacency with mainland in the standard diagram.
  • For each neighboring pair impose inequality: WA≠NT, WA≠SA, NT≠SA, NT≠Q, SA≠Q, SA≠NSW, SA≠V, Q≠NSW, NSW≠V.
  • A solution is an assignment satisfying every listed edge.
  • Writing the constraints explicitly prevents accidentally omitting a border.

Lesson B · Backtracking and ordering heuristics

  • Backtracking is depth-first search specialized to assignments.
  • It assigns one variable, checks constraints, and descends only when the partial assignment remains consistent.
  • If a variable has no legal value, it retracts earlier choices and tries another.
  • The method is complete for finite domains if it systematically tries all values, but worst-case effort is exponential.
  • Three heuristics reduce wasted search.
  • MRV chooses the variable with fewest legal values; this reveals a dead end as soon as possible.
  • Degree chooses the variable constraining the most remaining variables (tie-break).
  • LCV chooses the value that removes the fewest neighbor choices, preserving flexibility.

Map coloring trace with MRV/degree logic

  1. Initially all regions have 3 colors. SA has the most neighbors, so degree heuristic chooses SA.
  2. Set SA=R. Remove R from WA, NT, Q, NSW and V; their domains become {G,B}. T remains {R,G,B}.
  3. Choose NT. Try NT=G (a valid value); then WA, Q lose G. Because both also neighbor SA=R, WA and Q are forced to B.
  4. Q= B means NSW cannot be B; NSW also cannot be SA’s R, so NSW=G.
  5. V cannot be R (SA) or G (NSW), so V=B. T is independent and may take any color.
  6. Check all edges; the assignment is valid. If at any point a domain becomes empty, undo the most recent relevant assignment.
  • The exact order can differ with tie-breaking, but each attempted value must be checked against all assigned neighbors.

Lesson C · Forward checking and arc consistency

  • Search can learn from a choice before selecting every variable.
  • Forward checking removes from each unassigned neighbor any value incompatible with the newly assigned variable.
  • It detects an immediate empty domain but does not necessarily carry implications through a longer chain.
  • Arc consistency is stronger.
  • For each directed arc X→Y, every value in X’s domain must have at least one supporting value in Y’s domain satisfying their constraint.
  • If not, remove that value from X and revisit arcs pointing to X’s neighbors.
  • Repeat until no domain changes.
  • It can be used before search or after each assignment.
  • Arc consistency is a pruning method, not a guarantee that a complete solution exists.

Small numeric domain example

  • Let X,Y,Z each have domain {1,2,3}; constraints X<Y and Y<Z.
  1. For arc X→Y, X=3 has no supporting Y greater than 3, so remove 3 from D(X).
  2. For arc Y→Z, Y=3 has no supporting Z greater than 3, so remove 3 from D(Y).
  3. Revisit X→Y: X=2 now has no supporting Y greater than 2 because D(Y)={1,2}; remove 2 from D(X).
  4. Revisit Y→Z: Y=2 has no supporting Z greater than 2 because D(Z)={1,2,3} actually Z=3 supports it, so retain 2. X must be 1; then X<Y forces Y∈{2,3}; Y<Z retains support.
  5. Domains have been reduced without choosing a complete assignment; search can now start with fewer options.
  • When writing AC-3 by hand, name the arc, state which value lacks support, remove it, and show the updated domain.
  • This is the clearest way to earn process marks.

Lesson D · Intelligent backtracking and local search

  • Chronological backtracking returns to the last decision even when it did not cause failure.
  • Conflict-directed backjumping records which earlier assignments caused a variable’s domain to empty, then jumps to the most recent assignment in that conflict set.
  • If SA has no available color because of Q, NSW and V, changing Tasmania cannot fix it; backjumping avoids that irrelevant reversal.
  • Local search for CSP begins with a complete assignment (possibly inconsistent), then repeatedly changes a variable to reduce conflicts.
  • Min-conflicts chooses a conflicted variable and a value that minimizes violated constraints.
  • It can solve large scheduling-like instances quickly but may get trapped or fail to prove no solution exists.
  • Random restarts help; unlike backtracking, local search is not generally complete.

Cryptarithmetic as a constraint-satisfaction problem

  • Each letter is a variable and its domain is the decimal digits 0–9.
  • AllDifferent requires distinct letters to map to distinct digits.
  • Leading letters cannot be zero.
  • Each arithmetic column becomes a constraint with a carry variable.
  • Search assigns digits while propagation rejects inconsistent partial assignments.

SIMPLE NUMERICAL Australia map coloring: first assignment

GIVEN
  • Variables include WA, NT, SA, Q, NSW, V, T.
  • Domain for each region: {R,G,B}.
  • Adjacent regions must have different colors.
FORMULA / RULE
For every edge X–Y, require X ≠ Y. Assign SA=R and remove R from its neighbors.
STEPWISE WORKING
  1. SA is adjacent to WA, NT, Q, NSW and V.
  2. Remove R from each adjacent domain: D(WA)=D(NT)=D(Q)=D(NSW)=D(V)={G,B}.
  3. T is not adjacent to those regions in the standard map graph, so D(T) remains {R,G,B}.
FINAL ANSWER
The first assignment SA=R is valid and reduces five neighboring domains. See CSP formulation.

MEDIUM NUMERICAL Arc-consistency propagation

GIVEN
  • D(X)=D(Y)=D(Z)={1,2,3}.
  • Constraints: X<Y and Y<Z.
FORMULA / RULE
An arc value survives only if it has a supporting value in the neighboring domain. Repeat revisions until no domain changes.
STEPWISE WORKING
  1. Revise X→Y: X=3 has no Y>3, so remove 3. D(X)={1,2}.
  2. Revise Y→Z: Y=3 has no Z>3, so remove 3. D(Y)={1,2}.
  3. Revise X→Y again: X=2 has no supporting Y>2 in {1,2}; remove 2. D(X)={1}.
  4. Revise Y→X: Y=1 has no X<1 in {1}; remove 1. D(Y)={2}.
  5. Revise Z→Y: Z=1 and Z=2 have no supporting Y<Z; retain only Z=3.
FINAL ANSWER
The unique consistent assignment is X=1, Y=2, Z=3. See arc consistency.

COMPLEX NUMERICAL Cryptarithmetic: SEND + MORE = MONEY

GIVEN
  • Each letter is a distinct digit 0–9.
  • S and M cannot be zero.
  • Each column has carry cᵢ∈{0,1}.
FORMULA / RULE
Units: D+E=Y+10c₁; tens: N+R+c₁=E+10c₂; hundreds: E+O+c₂=N+10c₃; thousands: S+M+c₃=O+10c₄; leading column: c₄=M.
STEPWISE WORKING
  1. Because the sum has five digits, c₄=1; therefore M=1.
  2. Use the thousands column S+1+c₃=O+10. Since S is nonzero, the left side must reach at least 10; this constrains S to 8 or 9 and fixes O from the carry.
  3. Apply all-different digits and carry constraints to each remaining column; reject any partial assignment that repeats a digit or makes a carry outside {0,1}.
  4. A consistent assignment is S=9,E=5,N=6,D=7,M=1,O=0,R=8,Y=2.
  5. Verify units: 7+5=12, so Y=2,c₁=1.
  6. Verify tens: 6+8+1=15, so E=5,c₂=1.
  7. Verify hundreds: 5+0+1=6, so N=6,c₃=0.
  8. Verify thousands: 9+1+0=10, so O=0,c₄=1; leading M=1.
FINAL ANSWER
The verified solution is 9567 + 1085 = 10652. See cryptarithmetic as a CSP.

Lesson F · Exam method for any CSP

  • Start by listing variables, domains and constraints.
  • Draw the graph if constraints are binary.
  • State the search strategy and tie-breaking.
  • For every assignment, show domain reductions and consistency checks.
  • If failure occurs, identify the empty domain and the relevant conflict set.
  • Finish by checking every constraint—not just the final arithmetic or map picture.
  • For a comparison answer, distinguish search control (backtracking/local search), ordering heuristics (MRV/degree/LCV), and inference (forward checking/arc consistency).
