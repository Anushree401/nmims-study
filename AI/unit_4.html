1. In-Depth Theory & Lecture Explanation

1.1 Formal Definition of a CSP: ⟨X, D, C⟩

In standard state-space search (studied in Unit 2), states are treated as atomic "black boxes" evaluated solely by a heuristic function. A Constraint Satisfaction Problem (CSP) factors states into structured variables with assigned values, allowing general-purpose heuristics and constraint propagation to eliminate massive subspaces of illegal assignments without domain-specific search guidance.

The Formal 3-Tuple Definition of CSP

A Constraint Satisfaction Problem is formally defined as a 3-tuple:

$$\mathbf{\mathcal{P} = \langle X, D, C \rangle}$$
  • Variables \(X = \{X_1, X_2, \dots, X_n\}\): A finite set of variables to be assigned.
  • Domains \(D = \{D_1, D_2, \dots, D_n\}\): A set of candidate domain values for each variable, where \(X_i \in D_i\). Domains can be discrete (finite or infinite) or continuous.
  • Constraints \(C = \{C_1, C_2, \dots, C_m\}\): A set of constraints specifying allowable combinations of values across subsets of variables. Each constraint is a pair \(\langle \text{scope}, \text{relation} \rangle\).

States and Solutions in CSP:

  • State: Defined by an assignment of values to some or all variables: \(\{X_i = v_i, X_j = v_j, \dots\}\).
    • Consistent / Legal Assignment: Does not violate any constraints in \(C\).
    • Complete Assignment: Every variable in \(X\) is assigned a value.
    • Partial Assignment: Only some variables have values assigned.
  • Solution: A consistent and complete assignment.

1.2 Constraint Types & The Australia Map-Coloring Benchmark

Varieties of Constraints by Arity:

  1. Unary Constraints: Restrict the value of a single variable (e.g., \(\text{SouthAustralia} \neq \text{Green}\)). Unary constraints can be pre-processed by shrinking the domain \(D_i\).
  2. Binary Constraints: Relate two variables (e.g., \(\text{WesternAustralia} \neq \text{NorthernTerritory}\)). A CSP with only binary constraints is called a Binary CSP, represented as a Constraint Graph where nodes are variables and edges are constraints.
  3. Higher-Order / Global Constraints: Involve three or more variables (e.g., \(\text{Alldiff}(A, B, C, D)\) in Sudoku or column carries in Cryptarithmetic).

Benchmark: Australia Map Coloring

Assign colors \(\{\text{Red}, \text{Green}, \text{Blue}\}\) to the 7 territories of Australia such that no two adjacent regions share the same color:

  • Variables \(X\): \(\{\text{WA}, \text{NT}, \text{SA}, \text{Q}, \text{NSW}, \text{V}, \text{T}\}\).
  • Domains \(D\): \(D_i = \{\text{Red}, \text{Green}, \text{Blue}\} \quad \forall i\).
  • Constraints \(C\):

    \(\text{SA} \neq \text{WA}, \, \text{SA} \neq \text{NT}, \, \text{SA} \neq \text{Q}, \, \text{SA} \neq \text{NSW}, \, \text{SA} \neq \text{V}\)

    \(\text{WA} \neq \text{NT}, \, \text{NT} \neq \text{Q}, \, \text{Q} \neq \text{NSW}, \, \text{NSW} \neq \text{V}\)

    Note on Tasmania (\(\text{T}\)): Tasmania has no borders with any territory; it is an independent, disconnected component.

1.3 Backtracking Search & General Heuristics

Standard search algorithms (BFS/DFS) generate \(n! \cdot d^n\) states for CSPs because they do not recognize that variable assignment order is commutative. Backtracking Search is depth-first search that chooses values for a single variable at a time and backtracks immediately when a variable has no legal values.

The 3 General-Purpose CSP Heuristics:

1. Minimum Remaining Values (MRV / "Fail-First" Heuristic):

Variable Selection: Choose the unassigned variable that has the fewest legal values remaining in its domain. Rationale: It prunes the search tree earliest by failing fast on heavily constrained variables.

2. Degree Heuristic (Tie-Breaker for Variable Selection):

Variable Selection: Choose the variable that is involved in the largest number of constraints with other unassigned variables. (E.g., In Australia, South Australia has degree 5, making it the best initial variable).

3. Least Constraining Value (LCV / "Fail-Last" Heuristic):

Value Selection: Once a variable is chosen, pick the value that rules out the fewest choices for neighboring unassigned variables. Rationale: Keeps maximum flexibility open for future assignments.

1.4 Constraint Propagation: Forward Checking & AC-3

Rather than merely testing constraints after assignment, Constraint Propagation actively uses constraints to reduce domains before and during search.

1. Forward Checking:

Whenever a variable \(X\) is assigned a value \(v\), Forward Checking looks at each unassigned neighbor \(Y\) connected to \(X\) by a constraint and deletes from \(D_Y\) any value that is inconsistent with \(v\). If any domain becomes empty \(\emptyset\), backtrack immediately.

  • Limitation: Forward checking only looks one step ahead; it detects domain emptyings but does not detect cascading inconsistencies between unassigned neighbors.

2. Arc Consistency (AC-3 Algorithm):

Definition of Arc Consistency

A directed arc \(X_i \to X_j\) is arc-consistent if for every value \(x \in D_i\), there exists at least one value \(y \in D_j\) that satisfies the binary constraint on \((X_i, X_j)\).

The AC-3 Algorithm maintains a queue of all arcs in the CSP. When it removes a value from \(D_i\) to make \(X_i \to X_j\) consistent, it re-inserts all arcs \(X_k \to X_i\) pointing to \(X_i\) back into the queue to propagate cascading domain shrinkages.

  • Time Complexity of AC-3: \(O(c \cdot d^3)\), where \(c\) is the number of binary constraints and \(d\) is maximum domain size.

1.5 Intelligent Backtracking: Conflict Sets & Backjumping

Standard chronological backtracking backtracks to the immediately preceding variable in the assignment stack. If that variable has nothing to do with the failure, chronological backtracking wastes enormous computational effort searching fruitless subtrees (the thrashing problem).

Conflict-Directed Backjumping (CBJ):

Each variable maintains a Conflict Set: the set of previously assigned variables whose constraints caused values to be eliminated from its domain. When a variable's domain becomes empty, backjump directly to the most recently assigned variable in its conflict set, jumping over irrelevant intermediate variables.

Example: In Australia, if South Australia, Western Australia, etc., cause a failure in Victoria, but Tasmania was assigned right before Victoria, chronological backtracking fruitlessly tries all colors for Tasmania before realizing South Australia was the culprit. Backjumping jumps directly back over Tasmania to South Australia!

Problem 4.1: Australia Map Coloring Degree & MRV Heuristic Trace

Problem Statement: In the Australia map coloring problem with domains \(D_i = \{\text{Red}, \text{Green}, \text{Blue}\}\) across variables \(\{\text{WA}, \text{NT}, \text{SA}, \text{Q}, \text{NSW}, \text{V}, \text{T}\}\):

  1. Calculate the initial constraint degree of all 7 variables. Which variable will be selected first under the Degree Heuristic?
  2. If South Australia (\(\text{SA}\)) is assigned color Blue, what are the remaining domain sizes of its neighbors? Which variable will MRV choose next?
STEP 1

Compute initial degrees (number of neighbors in constraint graph):

  • \(\text{deg}(\text{SA}) = 5\) (Neighbors: WA, NT, Q, NSW, V) → MAXIMUM!
  • \(\text{deg}(\text{NT}) = 3\) (WA, SA, Q)
  • \(\text{deg}(\text{Q}) = 3\) (NT, SA, NSW)
  • \(\text{deg}(\text{NSW}) = 3\) (SA, Q, V)
  • \(\text{deg}(\text{WA}) = 2\) (NT, SA)
  • \(\text{deg}(\text{V}) = 2\) (SA, NSW)
  • \(\text{deg}(\text{T}) = 0\) (No borders)

Decision: Under the Degree Heuristic, South Australia (\(\text{SA}\)) is chosen first.

STEP 2

Forward Checking after \(\text{SA} = \text{Blue}\):

  • \(D_{\text{WA}} = \{\text{Red}, \text{Green}\}\) (Size = 2)
  • \(D_{\text{NT}} = \{\text{Red}, \text{Green}\}\) (Size = 2)
  • \(D_{\text{Q}} = \{\text{Red}, \text{Green}\}\) (Size = 2)
  • \(D_{\text{NSW}} = \{\text{Red}, \text{Green}\}\) (Size = 2)
  • \(D_{\text{V}} = \{\text{Red}, \text{Green}\}\) (Size = 2)
  • \(D_{\text{T}} = \{\text{Red}, \text{Green}, \text{Blue}\}\) (Size = 3)

All neighbors have domain size 2 (tied for MRV). Using Degree Heuristic as tie-breaker among unassigned variables:

  • \(\text{NT}, \text{Q}, \text{NSW}\) each have degree 2 with remaining unassigned variables. Any of these three will be selected next.
FINAL ANSWER

\(\mathbf{\text{Initial Variable Selected: South Australia (SA) with degree } 5.}\)

Medium Example

Problem 4.2: Step-by-Step Forward Checking Domain Reduction Trace

Problem Statement: Consider three variables \(X_1, X_2, X_3\) with initial domains: $$D_1 = \{1, 2\}, \quad D_2 = \{1, 2, 3\}, \quad D_3 = \{1, 2\}$$ Subject to binary constraints: \(X_1 < X_2\) and \(X_2 < X_3\).

Trace the execution of Backtracking with Forward Checking when \(X_1 = 1\) is assigned. Show domain reductions and explain whether a solution exists without further branching.

STEP 1

Assign \(X_1 = 1\):

Propagate constraint \(X_1 < X_2\): Delete any value \(v_2 \in D_2\) where \(1 \ge v_2\):

$$D_2 = \{2, 3\}$$

Current Domains: \(X_1 = \{1\}, D_2 = \{2, 3\}, D_3 = \{1, 2\}\).

STEP 2

Assign \(X_2 = 2\) (using MRV/LCV):

Propagate constraint \(X_2 < X_3\): Delete any value \(v_3 \in D_3\) where \(2 \ge v_3\):

Delete 1 and 2 from \(D_3\)!

$$\mathbf{D_3 = \emptyset \quad (\text{EMPTY DOMAIN DETECTED!})}$$

Forward checking detects failure immediately! Backtrack and try \(X_2 = 3\).

STEP 3

Try \(X_2 = 3\):

Propagate constraint \(3 < X_3\): Requires \(X_3 > 3\). But \(D_3 = \{1, 2\}\).

$$\mathbf{D_3 = \emptyset \quad (\text{EMPTY DOMAIN!})}$$

No valid value exists for \(X_2\) when \(X_1 = 1\). Backtrack on \(X_1\).

STEP 4

Try \(X_1 = 2\):

Constraint \(X_1 < X_2 \implies X_2 > 2 \implies D_2 = \{3\}\).

Constraint \(X_2 < X_3 \implies 3 < X_3 \implies D_3 = \emptyset\).

FINAL ANSWER

\(\mathbf{\text{CSP is Unsatisfiable (No solution exists for } X_1 < X_2 < X_3 \text{ with given domains).}}\)

Complex Example

Problem 4.3: Complete Analytical Trace of SEND + MORE = MONEY

Problem Statement: Formulate and solve the classical cryptarithmetic puzzle: $$\begin{array}{cccccc} & S & E & N & D \\ + & M & O & R & E \\ \hline M & O & N & E & Y \end{array}$$ where each letter is a unique decimal digit \(\in \{0, \dots, 9\}\), and leading digits \(S \neq 0, M \neq 0\). Show the complete mathematical deduction step-by-step.

STEP 1

Column 5 (Carries into 5th column):

$$C_4 = M$$

The sum of two 4-digit numbers can at most generate a carry of \(1\) (\(9999 + 9999 = 19998\)). Since \(M \neq 0\):

$$\mathbf{M = 1, \quad C_4 = 1}$$
STEP 2

Column 4 (Thousands column):

$$S + M + C_3 = O + 10 \cdot C_4 \implies S + 1 + C_3 = O + 10$$ $$S + C_3 = O + 9$$

Since \(S \le 9\), the maximum LHS is \(9 + 1 = 10\). Thus \(O\) can only be \(0\) or \(1\). But \(M = 1\) and digits are unique (\(\text{Alldiff}\)), so:

$$\mathbf{O = 0}$$

Substituting \(O = 0\): \(S + C_3 = 9\). If \(C_3 = 0\), then \(S = 9\). If \(C_3 = 1\), then \(S = 8\).

STEP 3

Column 3 (Hundreds column):

$$E + O + C_2 = N + 10 \cdot C_3 \implies E + 0 + C_2 = N + 10 \cdot C_3$$ $$E + C_2 = N + 10 \cdot C_3$$

If \(C_3 = 1\), then \(E + C_2 = N + 10\). Since \(E, N \le 9\) and \(C_2 \le 1\), this requires \(E = 9, N = 0\), violating uniqueness (\(O = 0\)). Thus:

$$\mathbf{C_3 = 0 \implies S = 9}$$

Now: \(E + C_2 = N\). Since \(E \neq N\), carry \(C_2\) must be 1:

$$\mathbf{C_2 = 1 \implies N = E + 1}$$
STEP 4

Column 2 (Tens column):

$$N + R + C_1 = E + 10 \cdot C_2 \implies (E + 1) + R + C_1 = E + 10$$ $$R + C_1 + 1 = 10 \implies R + C_1 = 9$$

Since \(S = 9\) already, \(R\) cannot be 9. Therefore, \(C_1\) must be 1:

$$\mathbf{C_1 = 1 \implies R = 8}$$
STEP 5

Column 1 (Units column):

$$D + E = Y + 10 \cdot C_1 \implies D + E = Y + 10$$

Digits remaining: \(\{2, 3, 4, 5, 6, 7\}\). We need \(D + E \ge 12\). Since \(N = E + 1\) and digits must be distinct, testing combinations yields:

$$\mathbf{E = 5 \implies N = 6}$$ $$D + 5 = Y + 10 \implies D = Y + 5$$

With remaining digits, \(D = 7\) gives \(Y = 2\)!

FINAL ANSWER

Final Unique Solution:

\(S=9, \, E=5, \, N=6, \, D=7, \, M=1, \, O=0, \, R=8, \, Y=2\)

$$\mathbf{9567 + 1085 = 10652}$$

Exam-Focused Tabular Comparisons

Table 4.1: Constraint Propagation Techniques: Forward Checking vs. AC-3

Comparison Dimension Forward Checking Arc Consistency (AC-3)
Scope of Propagation One step lookahead (only constraints between assigned variable and its immediate unassigned neighbors) Full cascading network propagation across all binary arcs in the graph
Inconsistency Detection Detects domain emptyings (\(D_Y = \emptyset\)) Detects subtle, multi-variable domain inconsistencies much earlier than forward checking

5. Possible University Exam Questions & Marking Guide

NMIMS Pattern: 4, 6, 8, 10 Marks
4 Marks

Q1. Formulate the Constraint Satisfaction Problem (CSP) as a formal 3-tuple. Differentiate between consistent and complete assignments.

Marking Scheme: 2 marks for \(\langle X, D, C \rangle\) tuple; 2 marks for consistent vs complete definitions.

Model Answer Key: Define \(\mathcal{P} = \langle X, D, C \rangle\). Consistent assignment violates no constraints. Complete assignment assigns every variable in \(X\) a value.

6 Marks

Q2. Explain the three general heuristics used in Backtracking Search: MRV, Degree Heuristic, and LCV.

Marking Scheme: 2 marks each for Minimum Remaining Values, Degree Heuristic, and Least Constraining Value.

Model Answer Key: Explain MRV ("fail-first" variable selection), Degree heuristic (most constraining variable tie-breaker), and LCV ("fail-last" value selection to maximize future domain flexibility).

8 Marks

Q3. Define Arc Consistency. Describe the working of the AC-3 algorithm step-by-step and state its worst-case time complexity.

Marking Scheme: 2 marks for arc consistency definition; 4 marks for algorithmic queue processing; 2 marks for complexity \(O(c \cdot d^3)\).

Model Answer Key: Define arc consistency. Detail the queue of arcs, how values lacking support are removed, and why neighboring arcs must be re-inserted. State \(O(c \cdot d^3)\).

10 Marks

Q4. Solve the Cryptarithmetic problem SEND + MORE = MONEY step-by-step, explaining the mathematical deduction for each letter.

Marking Scheme: 2 marks for problem formulation with carries; 6 marks for step-by-step deduction of all letters; 2 marks for final verified sum.

Model Answer Key: Provide the 5 column steps showing \(M=1\), \(O=0\), \(S=9\), \(R=8\), \(E=5\), \(N=6\), \(D=7\), \(Y=2\), resulting in \(9567 + 1085 = 10652\).
