1. In-depth theory explanation

Related: worked examples · comparative studies · case studies

1. Knowledge-based agents

  • A knowledge-based agent stores sentences in a knowledge base (KB), adds percepts using TELL, asks queries using ASK, and acts on the inferred answer.
  • Syntax determines legal sentences; semantics determines truth in a model.
  • Entailment KB ⊨ α means α is true in every model where KB is true.
  • Derivation KB ⊢ α means a proof procedure can derive α.
  • Soundness prevents false conclusions; completeness means every entailed conclusion is derivable.

2. Propositional logic

  • Atomic propositions are true or false.
  • Connectives: ¬ (not), ∧ (and), ∨ (or), → (implication), ↔ (biconditional).
  • Truth conditions matter: P→Q is false only when P=true and Q=false; it is equivalent to ¬P∨Q.
  • A tautology is true in every model, contradiction false in every model, and satisfiable if true in at least one model.

3. First-order logic (FOL)

  • FOL represents objects, properties, relations, functions and quantification.
  • Example: ∀x(Human(x)→Mortal(x)); Human(Socrates); therefore Mortal(Socrates).
  • Universal quantifier ∀ means every domain object; existential ∃ means at least one.
  • Variables are bound within quantifier scope; constants name objects; predicates express properties/relations.
  • Translation caution: “Every student reads a book” may mean ∀x(Student(x)→∃y(Book(y)∧Reads(x,y))). “There is one book every student reads” means ∃y(Book(y)∧∀x(Student(x)→Reads(x,y))).
  • Quantifier order changes meaning.
  • Propositional logic treats each whole assertion as an indivisible symbol; FOL exposes internal object structure and general rules, so it is more expressive but inference is more involved.

4. FOL inference and chaining

  • Universal instantiation (UI): from ∀x P(x), infer P(a) for a ground term a.
  • Existential instantiation (EI): from ∃x P(x), introduce a fresh constant c and infer P(c) for reasoning.
  • Generalized modus ponens matches rule premises to known facts and infers the conclusion.
  • Forward chaining is data-driven: start with facts, fire rules whose premises match, add conclusions, stop when query found or no new fact.
  • Backward chaining is goal-driven: start with query, find rules that could conclude it, then recursively prove their premises.
  • Forward chaining can generate irrelevant facts; backward chaining may revisit subgoals or loop without controls.

Worked chaining

  • Facts: Bird(Tweety), HasWings(Tweety).
  • Rules: Bird(x)∧HasWings(x)→CanFly(x); CanFly(x)→NeedsAirspace(x).
  1. Forward: match Bird and HasWings for x=Tweety; add CanFly(Tweety).
  2. Match CanFly; add NeedsAirspace(Tweety).
  3. Backward query NeedsAirspace(Tweety): use second rule; subgoal CanFly(Tweety); use first rule; subgoals Bird and HasWings are facts; query succeeds.

5. Resolution, CNF and worked proof

  • Resolution proves entailment by refutation: add the negation of the query to the KB, convert all clauses to conjunctive normal form (CNF), repeatedly resolve clauses containing complementary literals.
  • Deriving the empty clause □ means contradiction; therefore the original KB entails the query.
  • CNF conversion: eliminate ↔ and →; move ¬ inward using De Morgan and double-negation; standardize variables; remove existential quantifiers via Skolem constants/functions; distribute ∨ over ∧; drop universal quantifiers (implicit).
  • For propositional resolution, clause literals are complementary P and ¬P.

Simple inference

  • Given P and P→Q, apply modus ponens once: P=true and implication=true, therefore Q=true.

Medium: propositional resolution

  • KB clauses (P∨Q), (¬P∨R), ¬Q, ¬R.
  • Resolve first with ¬Q to get P; resolve second with ¬R to get ¬P; resolve P and ¬P to get □.
  • The clauses are inconsistent.

Complex: FOL refutation, Socrates is mortal

  1. KB: ∀x(Human(x)→Mortal(x)); Human(Socrates). Query: Mortal(Socrates).
  2. Negate query: ¬Mortal(Socrates).
  3. Convert rule: ¬Human(x)∨Mortal(x); fact Human(Socrates).
  4. Instantiate x=Socrates: ¬Human(Socrates)∨Mortal(Socrates).
  5. Resolve with Human(Socrates): Mortal(Socrates).
  6. Resolve with ¬Mortal(Socrates): □. Contradiction proves entailment.

Lesson A · Logic as a language for knowledge

  • Knowledge representation starts by choosing what exists in the world and how to describe it.
  • Logic provides a formal language with syntax (which expressions are legal) and semantics (when they are true).
  • A knowledge base stores sentences; an inference procedure derives consequences.
  • The central distinction is: truth is about the world/model; proof is about what the procedure can derive.
  • For example, “If it rains, the ground is wet” is a rule, not an observation.
  • If the fact Rain is known, modus ponens derives WetGround.
  • If Rain is not known, the rule alone does not establish whether the ground is wet.
  • This careful separation prevents an agent from treating plausible assumptions as facts.

Propositional connectives and truth conditions

  • Let P = “Amit studies” and Q = “Amit passes.” ¬P reverses truth; P∧Q requires both true; P∨Q is inclusive OR (at least one); P→Q is false only when P is true and Q false; P↔Q is true when both have the same truth value. “P only if Q” means P→Q; “P if Q” means Q→P.
  • These English patterns are common sources of reversed implications.

Lesson B · First-order logic adds objects and relations

  • Propositional logic might use one symbol, StudentA, for “A is a student,” but cannot express a general rule compactly.
  • First-order logic introduces a domain of objects, constants such as A, variables x, predicates such as Student(x), relations such as Likes(x,y), functions, and quantifiers.
  • ∀x(Student(x)→Studies(x)) says every student studies.
  • ∃x(Student(x)∧Studies(x)) says at least one student studies.
  • Notice the connective: for “all students study,” implication excludes nonstudents; for “there exists a student who studies,” conjunction requires both properties.

Translation worked examples

  1. “Every gardener likes the sun”: ∀x(Gardener(x)→Likes(x,Sun)).
  2. “Some student reads every book”: ∃x(Student(x)∧∀y(Book(y)→Reads(x,y))).
  3. “Every student reads some book”: ∀x(Student(x)→∃y(Book(y)∧Reads(x,y))). This does not require the same book for all students.
  4. “No cat is a dog”: ∀x(Cat(x)→¬Dog(x)), equivalently ¬∃x(Cat(x)∧Dog(x)).
  • Quantifier order changes meaning: ∀x∃y can allow a different y for each x; ∃y∀x selects one y that works for every x.
  • Bound variables can be renamed consistently; free variables make an open sentence whose truth depends on assignment.
  • Universal instantiation substitutes a ground term for a universally quantified variable.
  • Existential instantiation introduces a fresh name for an object guaranteed to exist; do not reuse a known constant because the witness might be a different object.

Lesson C · How inference derives new knowledge

  • Sound inference preserves truth: if its premises are true, its conclusion is true.
  • Completeness means the procedure can derive every conclusion entailed by its premises.
  • Modus ponens is the basic pattern: from P and P→Q infer Q.
  • Generalized modus ponens extends this to variables and matched rule premises.
  • Forward chaining is useful when new facts arrive and many conclusions may follow.
  • It repeatedly matches rules whose premises are known, adds conclusions, and stops at a fixed point.
  • Backward chaining is useful for a specific query: it asks which rule could establish the goal, then proves the rule’s premises as subgoals.
  • A practical system tracks already visited subgoals to avoid loops.

Same knowledge, two proof directions

  • Facts: Bird(Tweety), HasWings(Tweety).
  • Rules: Bird(x)∧HasWings(x)→CanFly(x); CanFly(x)→NeedsAirspace(x).
  • Forward: match first rule with x=Tweety; add CanFly(Tweety). Match second; add NeedsAirspace(Tweety). Query succeeds.
  • Backward query NeedsAirspace(Tweety): second rule creates subgoal CanFly(Tweety); first rule creates Bird(Tweety) and HasWings(Tweety); both are facts, so success.
  • Real systems need conflict handling and exceptions: “Birds generally fly” is not universally true.
  • Default reasoning is defeasible; new facts such as “Tweety is a penguin” may retract a previous conclusion.

Lesson D · Resolution as proof by contradiction

  • Resolution is a refutation method.
  • To prove KB entails Q, assume ¬Q and show that the enlarged set cannot be true.
  • Convert premises to clause form, resolve clauses with complementary literals, and derive the empty clause.
  • The empty clause means the assumptions require P and ¬P simultaneously.
  • For propositional conversion, remove implications with P→Q ≡ ¬P∨Q; push negations inward with De Morgan; distribute OR over AND; write each OR group as a clause and AND the clauses.
  • Example: P→(Q∧R) becomes ¬P∨(Q∧R), then (¬P∨Q)∧(¬P∨R).

Simple proof

  • Premises P and P→Q; query Q.
  • Negate query ¬Q.
  • Convert rule as ¬P∨Q.
  • Resolve with P to get Q; resolve with ¬Q to get □.
  • Therefore Q follows.

Medium proof

  • Given (P∨Q), (¬P∨R), ¬Q, ¬R: resolve (P∨Q) with ¬Q to obtain P.
  • Resolve (¬P∨R) with ¬R to obtain ¬P.
  • Resolve P and ¬P to obtain □, showing the clause set is inconsistent.

FOL proof, step by step

  1. Premises: ∀x(Human(x)→Mortal(x)); Human(Socrates). Goal: Mortal(Socrates).
  2. Negate goal: ¬Mortal(Socrates).
  3. Remove implication, obtaining ¬Human(x)∨Mortal(x).
  4. Instantiate x=Socrates: ¬Human(Socrates)∨Mortal(Socrates).
  5. Resolve with Human(Socrates), yielding Mortal(Socrates).
  6. Resolve with negated goal, yielding □. The negated goal is impossible with the KB; thus the goal is entailed.
  • For full FOL CNF, existential quantifiers are removed using Skolem constants/functions, universal quantifiers are implicit in clauses, and variables are standardized apart to avoid accidental capture.
  • Unification finds substitutions that make literals match; this is the key difference from simple propositional resolution.

SIMPLE WORKED LOGIC Modus ponens

GIVEN
  • Fact P is in the knowledge base.
  • Rule: P → Q.
FORMULA / RULE
From P and P → Q, infer Q.
STEPWISE WORKING
  1. Match the known fact P to the rule antecedent P.
  2. The rule conclusion is Q.
  3. Add Q to the knowledge base.
FINAL ANSWER
The KB entails Q. See propositional inference and forward chaining.

MEDIUM WORKED LOGIC Propositional resolution by refutation

GIVEN
  • Clauses: (P∨Q), (¬P∨R), ¬Q, ¬R.
  • Claim to test: the clauses are inconsistent.
FORMULA / RULE
Resolve (A∨L) with (B∨¬L) to obtain (A∨B); complementary literals cancel.
STEPWISE WORKING
  1. Resolve (P∨Q) with ¬Q; result is P.
  2. Resolve (¬P∨R) with ¬R; result is ¬P.
  3. Resolve P with ¬P; result is the empty clause □.
FINAL ANSWER
The clause set is unsatisfiable. For entailment questions, add the negated query and prove □. See resolution theory.

COMPLEX WORKED LOGIC First-order logic proof: Socrates is mortal

GIVEN
  • ∀x(Human(x) → Mortal(x)).
  • Human(Socrates).
  • Goal: Mortal(Socrates).
FORMULA / RULE
Refutation method: add ¬Goal, convert rules to clauses, instantiate variables, resolve complementary literals.
STEPWISE WORKING
  1. Negate the goal: ¬Mortal(Socrates).
  2. Remove implication: ¬Human(x)∨Mortal(x).
  3. Universal instantiation with x=Socrates gives ¬Human(Socrates)∨Mortal(Socrates).
  4. Resolve with Human(Socrates): obtain Mortal(Socrates).
  5. Resolve with ¬Mortal(Socrates): obtain □.
FINAL ANSWER
The KB entails Mortal(Socrates). See FOL and resolution.

7. Comparisons

Whole facts are symbols; compact, decidable by finite truth tables for finite atoms.Objects, predicates, relations, variables and quantifiers; more expressive; unrestricted entailment can be undecidable.

6. Wumpus World case study

  • The deck’s Wumpus World is a 4×4 cave: agent starts at (1,1); percepts include stench near Wumpus, breeze near pit, glitter on gold, scream when Wumpus dies, bump at wall.
  • Actions include move, turn, grab and shoot.
  • Performance rewards gold and penalizes death, movement and arrow use.
  • It is partially observable, sequential, static, discrete and single-agent; the world rules can be deterministic although uncertainty remains from hidden locations.
  • Inference illustration: let B12 mean breeze at (1,2), and P11/P13/P22 denote pits.
  • Rule: B12 ↔ (P11∨P13∨P22).
  • If P11 is known false because start is safe, then B12 ⇒ P13∨P22.
  • Do not claim which square is dangerous until more evidence arrives.
  • This is a real reasoning example from the deck, not a real-world incident.

Lesson E · Wumpus World: reasoning with incomplete observations

  • The Wumpus World is a deliberately small environment for showing how an agent reasons from local percepts to hidden hazards.
  • A breeze means a pit is in a neighboring square; stench means the Wumpus is adjacent; glitter means gold is here.
  • A percept is evidence, not a complete map.
  • The agent must avoid turning “possibly dangerous” into “certainly dangerous.”
  • Example: at (1,1), no breeze means adjacent squares (1,2) and (2,1) are pit-free (assuming the standard sensor rule).
  • At (1,2), a breeze means at least one neighboring square contains a pit.
  • If one neighbor is known safe, the other becomes a pit candidate.
  • Each new percept adds a constraint; inference intersects these constraints to classify squares as safe, hazardous or unknown.
  • This illustrates partially observable, sequential, discrete, static and single-agent properties.
  • The score rewards gold but penalizes death, moves and arrow use, so the agent balances information gathering against risk.
  • The representation and example are from the supplied Unit 3 slides.

5. Possible exam questions

8. Possible exam questions

  1. Explain the architecture and TELL/ASK cycle of a knowledge-based agent.
  2. Define syntax, semantics, entailment, soundness and completeness.
  3. Translate English statements into FOL and explain quantifier scope.
  4. Compare propositional and first-order logic.
  5. Explain UI, EI, modus ponens and generalized modus ponens with examples.
  6. Compare forward and backward chaining; trace a query using both.
  7. Convert formulas to CNF and prove a conclusion by resolution.
  8. Describe Wumpus World PEAS/percepts and infer safe or risky locations.

Lesson F · How to present a logic answer

  • State the domain and symbol meanings first.
  • Translate the English sentence with correct quantifier scope.
  • For a chaining trace, list facts, rule, substitution and newly derived fact at each firing.
  • For resolution, show the negated query, CNF clauses, each complementary literal removed, and the empty clause.
  • For a Wumpus inference, distinguish known safe, known hazardous and merely possible cells.
  • These labels make your reasoning inspectable.
