3.1 Knowledge-Based Agents & The TELL / ASK Interface

In search-based agents, the problem representation was atomic. In this unit, we explore Knowledge-Based Agents (KB Agents) that maintain an internal representation of the world expressed in formal declarative sentences.

A Knowledge-Based Agent is composed of two primary sub-systems:

  1. Knowledge Base (KB): A central repository containing a set of representations of facts of the world, each called a sentence, expressed in a knowledge representation language.
  2. Inference Engine: Algorithms for deriving new valid sentences from existing ones.

The agent interacts with its KB through a canonical interface:

  • TELL: Inserts new percepts and world observations into the KB.
  • ASK: Queries the KB to determine what action to perform next.
Language Implementation: KB agents execute TELL using Propositional Logic or First Order Logic (FOL), and execute ASK using Resolution, Forward Chaining, or Backward Chaining.

3.2 The Wumpus World Environment (The Standard AI Testbed)

The Wumpus World is a classic grid cave environment used throughout AI literature to demonstrate the power of logical deduction under partial observability:

1. PEAS Description of Wumpus World

  • Performance Measure: +1000 for grabbing the gold, -1000 for falling into a bottomless pit or being eaten by the Wumpus, -1 for each move taken, -10 for using up the single arrow.
  • Environment: A 4×4 grid of 16 rooms. The agent always starts at room (1,1) facing right. Room (1,1) is guaranteed free of pits and Wumpus.
  • Actuators: Move Forward, Turn Left 90°, Turn Right 90°, Grab Gold, Shoot Arrow (shoots straight in direction facing, kills Wumpus if aligned).
  • Sensors (5-Element Percept Vector):
    1. Stench: In rooms directly adjacent (horizontally or vertically) to the Wumpus.
    2. Breeze: In rooms directly adjacent to a Pit.
    3. Glitter: In the exact room containing the Gold.
    4. Bump: Perceived when walking into an outer perimeter wall.
    5. Scream: Heard globally across the cave when the Wumpus is killed.

3.3 Propositional Logic (Syntax, Semantics, Entailment)

Propositional Logic is the simplest formal logic language. A proposition is a declarative statement that is either True or False, but not both.

  • Syntax:
    • Atomic Sentences: Single propositional symbols: $P, Q, R, \text{WumpusAhead}$.
    • Five Logical Connectives: Negation $\neg $ (NOT), Conjunction $\wedge$ (AND), Disjunction $\vee$ (OR), Implication $ o$ (IF-THEN), Biconditional $\leftrightarrow$ (IFF).
  • Semantics & Truth Table:
$A$$B$$\neg B$$A \wedge B$$A \vee B$$A o B$$A \leftrightarrow B$
TTFTTTT
TFTFTFF
FTFFTTF
FFTFFTT
Crucial Exam Rule: The implication $A o B$ is False if and only if the premise $A$ is True and the consequence $B$ is False! In all other cases, $A o B$ evaluates to True.

Key Semantic Concepts:

  • Tautology (Valid Sentence): A sentence that is True under all possible interpretations (e.g., $P \vee \neg P$).
  • Contradiction (Inconsistent Sentence): A sentence that is False under all possible interpretations (e.g., $P \wedge \neg P$).
  • Logical Entailment ($\alpha \models \beta$): Sentence $\alpha$ entails sentence $\beta$ if and only if in every model where $\alpha$ is True, $\beta$ is also True.
  • Soundness vs. Completeness of Inference:
    • Soundness: An inference procedure is sound if it derives only real entailments ($KB \vdash \alpha \implies KB \models \alpha$). It never makes false deductions.
    • Completeness: An inference procedure is complete if it can derive all valid sentences ($KB \models \alpha \implies KB \vdash \alpha$).

3.4 First-Order Logic (FOL / Predicate Logic)

While propositional logic is declarative, it suffers from severe limitations: it assumes the world consists only of atomic facts, lacking expressive power to generalize statements like "All purple mushrooms are poisonous."

First-Order Logic (FOL) models the world with richer ontological commitment:

  1. Objects: Entities with individual identities (e.g., John, Apple, Student1).
  2. Properties: Traits that distinguish objects (e.g., $\text{Purple}(x)$, $\text{Poisonous}(x)$).
  3. Relations: Relationships holding among objects (e.g., $\text{BrotherOf}(x, y)$, $\text{Eats}(x, y)$).
  4. Functions: Relations that return exactly one value for any given input (e.g., $\text{FatherOf}(x)$, $\text{Plus}(x, y)$).

Quantifiers in FOL

  • Universal Quantifier ($\forall x$): Represents "For all $x$". Corresponds to logical conjunction ($\wedge$). Universal statements are standardly paired with Implication ($ o$):
    "All students are smart" → ∀x (Student(x) → Smart(x))
  • Existential Quantifier ($\exists x$): Represents "There exists at least one $x$". Corresponds to logical disjunction ($\vee$). Existential statements are standardly paired with Conjunction ($\wedge$):
    "There is a student who is smart" → ∃x (Student(x) ∧ Smart(x))

Standard English to FOL Translation Practice (from Slide 21)

English SentenceFirst Order Logic (FOL) Representation
"Every gardener likes the sun."$\forall x\ (\text{Gardener}(x) o \text{Likes}(x, \text{Sun}))$
"You can fool some of the people all of the time."$\exists x \forall t\ (\text{Person}(x) \wedge \text{Time}(t) o \text{CanFool}(x, t))$
"You can fool all of the people some of the time."$\forall x \exists t\ (\text{Person}(x) \wedge \text{Time}(t) o \text{CanFool}(x, t))$

"Clinton is not tall."$\neg \text{Tall}(\text{Clinton})$

3.5 Inference Rules in First-Order Logic & Unification

  • Universal Instantiation (UI): From $\forall v\ \alpha$, we can infer $\text{SUBST}(\{v / g\}, \alpha)$ for any variable $v$ and ground term $g$:
    ∀x (King(x) ∧ Greedy(x) → Evil(x)) ⇒ King(John) ∧ Greedy(John) → Evil(John) [by subst {x/John}]
  • Existential Instantiation (EI) / Skolemization: From $\exists v\ \alpha$, we can infer $\text{SUBST}(\{v / k\}, \alpha)$, where $k$ is a brand new constant symbol called a Skolem constant that has never appeared anywhere in the KB:
    ∃x (Crown(x) ∧ OnHead(x, John)) ⇒ Crown(C1) ∧ OnHead(C1, John)
  • Unification: The algorithmic process of finding a substitution $ heta$ that makes two different logical expressions identical:
    UNIFY(Knows(John, x), Knows(John, Jane)) ⇒ θ = {x / Jane} UNIFY(Knows(John, x), Knows(y, Bill)) ⇒ θ = {x / Bill, y / John} UNIFY(Knows(John, x), Knows(x, Elizabeth)) ⇒ FAILS (x cannot simultaneously be John and Elizabeth)

3.6 Production Rule Systems & The Water Jug Problem

A production system is a modular cognitive AI architecture consisting of:

  • Working Memory: A global database storing current state facts.
  • Production Rules: Condition-Action pairs: IF <condition> THEN <action>.
  • Rule Interpreter / Conflict Resolver: Determines which rule to fire when multiple preconditions match.

3.7 Forward Chaining vs. Backward Chaining

  • Forward Chaining (Data-Driven): Starts with known facts in the KB, searches for rules whose premises (antecedents) are satisfied, fires them, and adds the consequents as new facts into the KB. Repeats until the target goal is derived.
    Best used: When new facts arrive periodically and many conclusions need to be monitored (e.g., monitoring pipelines, synthesis).
  • Backward Chaining (Goal-Driven): Starts with the hypothesis/query goal, works backward by searching for rules whose consequents match the goal, and places the antecedents on a goal stack as sub-goals to prove.
    Best used: When a specific question is asked and the set of relevant facts is small (e.g., diagnostic expert systems like MYCIN).

3.8 Conjunctive Normal Form (CNF) & Resolution Refutation

Resolution is an automated theorem-proving inference rule based on proof by contradiction (reductio ad absurdum). To prove $KB \models \alpha$, we assert $\neg \alpha$ into the KB, convert all sentences into Conjunctive Normal Form (CNF), and systematically resolve complementary literals until deriving the empty clause ($\Box$ or NULL), which indicates a contradiction.

The 5 Steps to Convert FOL into CNF (from Slides 57–62)

  1. Step 1: Eliminate Implications ($ o, \leftrightarrow$):
    Replace $\alpha o \beta$ with $\neg \alpha \vee \beta$.
    Replace $\alpha \leftrightarrow \beta$ with $(\neg \alpha \vee \beta) \wedge (\neg \beta \vee \alpha)$.
  2. Step 2: Move Negation ($\neg $) Inwards (De Morgan's Laws):
    $\neg (\forall x\ P) \equiv \exists x\ \neg P$
    $\neg (\exists x\ P) \equiv \forall x\ \neg P$
    $\neg (\alpha \wedge \beta) \equiv \neg \alpha \vee \neg \beta$
    $\neg (\alpha \vee \beta) \equiv \neg \alpha \wedge \neg \beta$
    $\neg \neg \alpha \equiv \alpha$
  3. Step 3: Standardize / Rename Variables: Ensure each quantifier uses unique variable names across clauses.
  4. Step 4: Skolemization (Eliminate $\exists$): Replace existential variables with Skolem constants or Skolem functions.
  5. Step 5: Drop Universal Quantifiers ($\forall$): Because all remaining variables are universally quantified, drop prefixes $\forall x$.

MEDIUM Step-by-Step Forward Chaining Trace (Fritz the Frog)

GIVEN KNOWLEDGE BASE (from Slides 33–43):
  • R1: IF [X croaks and eats flies] THEN [X is a frog]
  • R2: IF [X chirps and sings] THEN [X is a canary]
  • R3: IF [X is a frog] THEN [X is colored green]
  • R4: IF [X is a canary] THEN [X is colored yellow]
  • Fact 1: [Fritz croaks and eats flies]
Query Goal: What is Fritz's color? [Fritz is colored Y]?
STEPWISE WORKING:
  1. Cycle 1: Examine KB facts. Working memory has [Fritz croaks and eats flies].
    Match with R1 premise: X = Fritz.
    Fire Rule 1 → Add new fact to KB: [Fritz is a frog].
  2. Cycle 2: Match newly added fact [Fritz is a frog] with R3 premise: X = Fritz.
    Fire Rule 3 → Add new fact to KB: [Fritz is colored green].
  3. Cycle 3: Match [Fritz is colored green] against query [Fritz is colored Y]?.
    Unification succeeds with substitution: \(Y = \text{green}\).
FINAL ANSWER: Derived conclusion: Fritz is colored green (\(Y = \text{green}\)).

COMPLEX Complete Resolution Refutation Proof ("John Likes Peanuts")

GIVEN ENGLISH STATEMENTS (from Slides 64–70):
  1. John likes all kind of food: \(\forall x\ (\text{Food}(x) o \text{Likes}(\text{John}, x))\)
  2. Apple and vegetable are food: \(\text{Food}(\text{Apple}) \wedge \text{Food}(\text{Vegetables})\)
  3. Anything anyone eats and not killed is food: \(\forall x \forall y\ (\text{Eats}(x, y) \wedge \neg \text{Killed}(x) o \text{Food}(y))\)
  4. Anil eats peanuts and is still alive: \(\text{Eats}(\text{Anil}, \text{Peanuts}) \wedge \text{Alive}(\text{Anil})\)
  5. Harry eats everything that Anil eats: \(\forall x\ (\text{Eats}(\text{Anil}, x) o \text{Eats}(\text{Harry}, x))\)
  6. Added background knowledge: \(\forall x\ (\text{Alive}(x) o \neg \text{Killed}(x))\)
Prove by Resolution: "John likes peanuts" (\(\text{Likes}(\text{John}, \text{Peanuts})\)).
CONVERT TO CNF CLAUSES:
  • C1: \(\neg \text{Food}(x) \vee \text{Likes}(\text{John}, x)\)
  • C2: \(\neg \text{Eats}(y, z) \vee \text{Killed}(y) \vee \text{Food}(z)\)
  • C3: \(\text{Eats}(\text{Anil}, \text{Peanuts})\)
  • C4: \(\text{Alive}(\text{Anil})\)
  • C5: \(\neg \text{Alive}(k) \vee \neg \text{Killed}(k)\)
  • Negated Goal Clause (C6): \(\neg \text{Likes}(\text{John}, \text{Peanuts})\)
RESOLUTION REFUTATION TREE TRACE:
  1. Resolve Negated Goal C6 [\(\neg \text{Likes}(\text{John}, \text{Peanuts})\)] with C1 [\(\neg \text{Food}(x) \vee \text{Likes}(\text{John}, x)\)] using substitution \(\{x / \text{Peanuts}\}\):
    → Resolvent C7: \(\neg \text{Food}(\text{Peanuts})\)
  2. Resolve C7 [\(\neg \text{Food}(\text{Peanuts})\)] with C2 [\(\neg \text{Eats}(y, z) \vee \text{Killed}(y) \vee \text{Food}(z)\)] using substitution \(\{z / \text{Peanuts}\}\):
    → Resolvent C8: \(\neg \text{Eats}(y, \text{Peanuts}) \vee \text{Killed}(y)\)
  3. Resolve C8 with C3 [\(\text{Eats}(\text{Anil}, \text{Peanuts})\)] using substitution \(\{y / \text{Anil}\}\):
    → Resolvent C9: \(\text{Killed}(\text{Anil})\)
  4. Resolve C9 [\(\text{Killed}(\text{Anil})\)] with C5 [\(\neg \text{Alive}(k) \vee \neg \text{Killed}(k)\)] using substitution \(\{k / \text{Anil}\}\):
    → Resolvent C10: \(\neg \text{Alive}(\text{Anil})\)
  5. Resolve C10 [\(\neg \text{Alive}(\text{Anil})\)] with Fact C4 [\(\text{Alive}(\text{Anil})\)]:
    → Resolvent: $\Box$ (EMPTY CLAUSE / CONTRADICTION)!
FINAL ANSWER: Derivation of the empty clause ($\Box$) contradicts our negated assumption. Therefore, the statement "John likes peanuts" is mathematically proven to be TRUE.
