1.1 Knowledge-Based Agents (KBA) & The Wumpus World

A Knowledge-Based Agent (KBA) is an intelligent agent whose central component is a Knowledge Base (KB): a set of sentences expressed in a formal knowledge representation language. KBAs operate via two core primitive operations:

  • \(\text{TELL}(KB, \text{sentence})\): Adds new assertions, percepts, or background axioms into the Knowledge Base.
  • \(\text{ASK}(KB, \text{query})\): Queries the Knowledge Base to determine whether a hypothesis is logically entailed by stored knowledge (\(KB \models \alpha\)).

The Wumpus World Benchmark Environment:

The Wumpus World is an exploration benchmark consisting of a \(4 \times 4\) grid cave surrounded by walls:

  • Agent: Starts in square \([1, 1]\), facing East.
  • Wumpus: A beast that eats anyone entering its square. Stays stationary. Emits a foul Stench in all immediately adjacent (cardinal) squares.
  • Pits: Bottomless traps scattered across the grid with probability \(0.20\). Any square adjacent to a pit experiences a Breeze.
  • Gold: Glitter is perceived if and only if the agent is in the exact square containing the gold.
  • Sensory Percept Vector: At each time step, the agent receives a 5-element percept vector: $$\mathbf{\text{Percept}} = [\text{Stench}, \text{Breeze}, \text{Glitter}, \text{Bump}, \text{Scream}]$$

1.2 Propositional Logic: Syntax, Semantics, Truth Tables

Propositional Logic (Boolean Logic) is the simplest formal logic system. It represents atomic declarative propositions that can be either True or False.

Logical Connectives:

  • Negation (\(\neg\)): NOT operator. \(\neg P\) is True iff \(P\) is False.
  • Conjunction (\(\wedge\)): AND operator. \(P \wedge Q\) is True iff both \(P\) and \(Q\) are True.
  • Disjunction (\(\vee\)): OR operator. \(P \vee Q\) is True if at least one operand is True.
  • Implication (\(\to\)): IF-THEN operator. \(P \to Q \equiv \neg P \vee Q\). Only False when premise \(P\) is True and conclusion \(Q\) is False.
  • Biconditional (\(\leftrightarrow\)): IFF operator. \(P \leftrightarrow Q\) is True iff both operands have identical truth values.

Key Semantic Concepts:

  • Validity / Tautology: A sentence that is True under all possible interpretations / truth assignments (e.g., \(P \vee \neg P\)).
  • Satisfiability: A sentence is satisfiable if there exists at least one truth assignment that makes it True.
  • Unsatisfiability / Contradiction: A sentence that is False in every possible interpretation (e.g., \(P \wedge \neg P\)).
  • Logical Entailment (\(\alpha \models \beta\)): Sentence \(\alpha\) entails sentence \(\beta\) if and only if in every model where \(\alpha\) is True, \(\beta\) is also True.

1.3 First-Order Logic (FOL / Predicate Logic)

While propositional logic can only represent zero-order facts, First-Order Logic (FOL) provides expressive ontological commitment: the world consists of Objects, Relations / Predicates, and Functions.

Quantifiers in FOL:

  • Universal Quantifier (\(\forall x\)): Asserts that a predicate holds for all entities in the universe of discourse. It acts as an iterated conjunction (\(\wedge\)): $$\forall x \, (\text{King}(x) \to \text{Person}(x))$$ Golden Rule: The main connective with \(\forall\) is almost always an implication (\(\to\)).
  • Existential Quantifier (\(\exists x\)): Asserts that a predicate holds for at least one entity. It acts as an iterated disjunction (\(\vee\)): $$\exists x \, (\text{Crown}(x) \wedge \text{OnHead}(x, \text{John}))$$ Golden Rule: The main connective with \(\exists\) is almost always a conjunction (\(\wedge\)).

English-to-FOL Translation Reference:

Natural Language Sentence First-Order Logic Representation
"Marcus was a man." \(\text{Man}(\text{Marcus})\)
"All men are mortal." \(\forall x \, (\text{Man}(x) \to \text{Mortal}(x))\)
"Everyone loves someone." \(\forall x \, \exists y \, \text{Loves}(x, y)\)
"There is someone who is loved by everyone." \(\exists y \, \forall x \, \text{Loves}(x, y)\)
"Brothers are siblings." \(\forall x, y \, (\text{Brother}(x, y) \to \text{Sibling}(x, y))\)

1.4 Inference Rules & The Unification Algorithm

To perform automated reasoning across quantified FOL sentences, agents lift propositional inference rules using Unification: finding a variable substitution \(\theta = \{v_1 / t_1, v_2 / t_2, \dots\}\) that makes two syntactically distinct logical expressions identical:

$$\text{UNIFY}(p, q) = \theta \quad \text{such that} \quad \text{Subst}(\theta, p) = \text{Subst}(\theta, q)$$

Canonical Unification Examples:

  • \(\text{UNIFY}(\text{Knows}(\text{John}, x), \text{Knows}(\text{John}, \text{Jane})) = \{x / \text{Jane}\}\)
  • \(\text{UNIFY}(\text{Knows}(\text{John}, x), \text{Knows}(y, \text{Bill})) = \{x / \text{Bill}, y / \text{John}\}\)
  • \(\text{UNIFY}(\text{Knows}(\text{John}, x), \text{Knows}(x, \text{Mother}(x))) = \text{FAIL}\) (due to variable name collision; requires Standardizing Variables Apart).

1.5 Production Systems & The Water Jug Problem

A Production System consists of a set of declarative production rules of the form IF <pattern> THEN <action>, a dynamic Working Memory, and an execution cycle (Recognize-Act).

The Water Jug Problem (Complete 10-Rule Formulation):

Given two unmeasured water jugs with capacities of 4 gallons (Jug \(X\)) and 3 gallons (Jug \(Y\)), and an unlimited pump. The goal is to obtain exactly 2 gallons in the 4-gallon jug (\(X=2, Y=0\)).

The 10 Production Rules for the Water Jug Problem:

  1. (x, y) if x < 4 → (4, y): Fill the 4-gallon jug completely.
  2. (x, y) if y < 3 → (x, 3): Fill the 3-gallon jug completely.
  3. (x, y) if x > 0 → (x - d, y): Pour some water out of the 4-gallon jug.
  4. (x, y) if y > 0 → (x, y - d): Pour some water out of the 3-gallon jug.
  5. (x, y) if x > 0 → (0, y): Empty the 4-gallon jug on the ground.
  6. (x, y) if y > 0 → (x, 0): Empty the 3-gallon jug on the ground.
  7. (x, y) if x + y ≥ 4 and y > 0 → (4, y - (4 - x)): Pour water from 3-gal jug into 4-gal jug until 4-gal jug is full.
  8. (x, y) if x + y ≥ 3 and x > 0 → (x - (3 - y), 3): Pour water from 4-gal jug into 3-gal jug until 3-gal jug is full.
  9. (x, y) if x + y ≤ 4 and y > 0 → (x + y, 0): Pour all water from 3-gal jug into 4-gal jug.
  10. (x, y) if x + y ≤ 3 and x > 0 → (0, x + y): Pour all water from 4-gal jug into 3-gal jug.

1.6 Forward Chaining vs. Backward Chaining

Production systems execute rules via two classic chaining strategies:

  • Forward Chaining (Data-Driven): Starts with known facts in working memory. Matches facts against rule IF-conditions (premises) and fires them to assert new facts into working memory. Continues in a Recognize-Act cycle until the goal is proven or no new rules can fire.
    • Best Suited For: Monitoring, planning, reactive systems, and configurations.
  • Backward Chaining (Goal-Driven): Starts with a hypothesis (the goal query). Finds rules whose THEN-consequents conclude that goal, and works backward, treating the premises as subgoals that must be proven. Recursively evaluates subgoals by querying the user or matching known facts.
    • Best Suited For: Diagnostic troubleshooting, medical diagnosis (e.g., MYCIN), and interactive query systems.

1.7 Conjunctive Normal Form (CNF) & Resolution Refutation

Resolution (J. Alan Robinson, 1965) is a sound and complete refutation inference rule. To prove that a Knowledge Base entails query \(\alpha\) (\(KB \models \alpha\)):

$$\mathbf{\text{Assert } \neg \alpha \text{ into the KB and derive a Contradiction (Empty Clause } \square)}$$

The 5-Step Algorithm to Convert First-Order Logic to CNF:

  1. Step 1: Eliminate Implications and Biconditionals:
    • Replace \(\alpha \to \beta\) with \(\neg \alpha \vee \beta\).
    • Replace \(\alpha \leftrightarrow \beta\) with \((\neg \alpha \vee \beta) \wedge (\neg \beta \vee \alpha)\).
  2. Step 2: Move Negations Inwards (De Morgan's Laws):
    • \(\neg (\forall x \, P) \equiv \exists x \, \neg P\), \quad \(\neg (\exists x \, P) \equiv \forall x \, \neg P\)
    • \(\neg (\alpha \wedge \beta) \equiv \neg \alpha \vee \neg \beta\), \quad \(\neg (\alpha \vee \beta) \equiv \neg \alpha \wedge \neg \beta\)
    • \(\neg \neg \alpha \equiv \alpha\)
  3. Step 3: Standardize Variables Apart: Rename duplicate variable names used across different quantifiers (e.g., replace \((\forall x \, P(x)) \vee (\exists x \, Q(x))\) with \((\forall x \, P(x)) \vee (\exists y \, Q(y))\)).
  4. Step 4: Skolemization (Eliminate Existential Quantifiers):
    • If \(\exists x\) is not inside a \(\forall\), replace \(x\) with a unique constant: Skolem Constant (e.g., \(A\)).
    • If \(\exists x\) is inside universal quantifiers \(\forall y_1 \dots \forall y_k\), replace \(x\) with a Skolem Function \(F(y_1, \dots, y_k)\).
  5. Step 5: Drop Universal Quantifiers & Distribute \(\vee\) over \(\wedge\): Drop explicit \(\forall\) prefixes (all variables are implicitly universally quantified) and distribute \(\alpha \vee (\beta \wedge \gamma) \equiv (\alpha \vee \beta) \wedge (\alpha \vee \gamma)\) to produce a set of disjunctive clauses.

Medium Example

Problem 3.2: Forward Chaining Deductive Trace

Problem Statement: Consider the following Knowledge Base about animals:

  • R1: IF \(\text{Croaks}(x)\) AND \(\text{EatsFlies}(x)\) THEN \(\text{Frog}(x)\)
  • R2: IF \(\text{Frog}(x)\) THEN \(\text{Green}(x)\)
  • R3: IF \(\text{Chirps}(x)\) AND \(\text{Sings}(x)\) THEN \(\text{Canary}(x)\)
  • R4: IF \(\text{Canary}(x)\) THEN \(\text{Yellow}(x)\)

Initial facts in Working Memory: \(\{\text{Croaks}(\text{Fritz}), \text{EatsFlies}(\text{Fritz})\}\). Prove whether the query \(\text{Green}(\text{Fritz})\) is entailed using Forward Chaining.

CYCLE 1

Pattern Matching: Check premises against \(WM_0 = \{\text{Croaks}(\text{Fritz}), \text{EatsFlies}(\text{Fritz})\}\):

Rule R1 premises are satisfied with \(\theta = \{x / \text{Fritz}\}\). Fire R1.

Assert: \(\text{Frog}(\text{Fritz})\) into Working Memory.

Updated \(WM_1 = \{\text{Croaks}(\text{Fritz}), \text{EatsFlies}(\text{Fritz}), \text{Frog}(\text{Fritz})\}\).

CYCLE 2

Pattern Matching: Check premises against \(WM_1\):

Rule R2 premise \(\text{Frog}(x)\) is now satisfied with \(\theta = \{x / \text{Fritz}\}\). Fire R2.

Assert: \(\text{Green}(\text{Fritz})\) into Working Memory.

Updated \(WM_2 = \{\text{Croaks}(\text{Fritz}), \text{EatsFlies}(\text{Fritz}), \text{Frog}(\text{Fritz}), \mathbf{\text{Green}(\text{Fritz})}\}\).

FINAL ANSWER

\(\mathbf{\text{Target Query } \text{Green}(\text{Fritz}) \text{ is proven True via inference sequence } R1 \to R2.}\)

Complex Example

Problem 3.3: First-Order Logic Resolution Refutation Proof

Problem Statement: Given the natural language statements:

  1. "Marcus was a man."
  2. "Marcus was a Pompeian."
  3. "All Pompeians were Romans."
  4. "Caesar was a ruler."
  5. "All Romans were either loyal to Caesar or hated him."
  6. "Everyone is loyal to someone."
  7. "People only try to assassinate rulers they are not loyal to."
  8. "Marcus tried to assassinate Caesar."

Prove by Resolution Refutation that: "Marcus hated Caesar."

CNF CLAUSES
  1. \(C_1: \text{Man}(\text{Marcus})\)
  2. \(C_2: \text{Pompeian}(\text{Marcus})\)
  3. \(C_3: \neg \text{Pompeian}(x_1) \vee \text{Roman}(x_1)\)
  4. \(C_4: \text{Ruler}(\text{Caesar})\)
  5. \(C_5: \neg \text{Roman}(x_2) \vee \text{LoyalTo}(x_2, \text{Caesar}) \vee \text{Hate}(x_2, \text{Caesar})\)
  6. \(C_6: \neg \text{Man}(x_3) \vee \neg \text{Ruler}(y_1) \vee \neg \text{TryAssassinate}(x_3, y_1) \vee \neg \text{LoyalTo}(x_3, y_1)\)
  7. \(C_7: \text{TryAssassinate}(\text{Marcus}, \text{Caesar})\)
  8. Negated Goal \(C_8\): \(\neg \text{Hate}(\text{Marcus}, \text{Caesar})\)
RESOLUTION TRACE
  1. Resolve \(C_8\) with \(C_5\) with \(\{x_2 / \text{Marcus}\}\):
    \(\implies C_9: \neg \text{Roman}(\text{Marcus}) \vee \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  2. Resolve \(C_9\) with \(C_3\) with \(\{x_1 / \text{Marcus}\}\):
    \(\implies C_{10}: \neg \text{Pompeian}(\text{Marcus}) \vee \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  3. Resolve \(C_{10}\) with \(C_2\):
    \(\implies C_{11}: \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  4. Resolve \(C_6\) with \(C_7\) with \(\{x_3 / \text{Marcus}, y_1 / \text{Caesar}\}\):
    \(\implies C_{12}: \neg \text{Man}(\text{Marcus}) \vee \neg \text{Ruler}(\text{Caesar}) \vee \neg \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  5. Resolve \(C_{12}\) with \(C_1\) (\(\text{Man}(\text{Marcus})\)):
    \(\implies C_{13}: \neg \text{Ruler}(\text{Caesar}) \vee \neg \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  6. Resolve \(C_{13}\) with \(C_4\) (\(\text{Ruler}(\text{Caesar})\)):
    \(\implies C_{14}: \neg \text{LoyalTo}(\text{Marcus}, \text{Caesar})\)
  7. Resolve \(C_{14}\) with \(C_{11}\) (\(\text{LoyalTo}(\text{Marcus}, \text{Caesar})\)):
    \(\implies \mathbf{\square \quad (\text{EMPTY CLAUSE / CONTRADICTION DERIVED!})}\)
FINAL ANSWER

Since the negated goal leads directly to an empty clause \(\square\), the query “Marcus hated Caesar” is proven true.

Exam-Focused Tabular Comparisons

Table 3.1: Propositional Logic vs. First-Order Logic (FOL)

Comparison Dimension Propositional Logic First-Order Logic (FOL)
Ontological Commitment Facts that are either True or False in the world Objects, Relations, Predicates, and Functions
Expressiveness Low (cannot express "all humans" without writing millions of conjunctions) High (concisely captures infinite generalities via quantifiers \(\forall, \exists\))
Decidability Decidable (truth tables always terminate in \(2^n\) steps) Semi-decidable (if sentence is entailed, proof will terminate; if not, may loop indefinitely)
Computational Complexity NP-Complete (Boolean Satisfiability - SAT) Undecidable in the worst case

Dimension Forward Chaining (Data-Driven) Backward Chaining (Goal-Driven)
Starting State Initial known facts in Working Memory Target query or hypothesis (Goal)
Direction of Inference Bottom-Up (Antecedent → Consequent) Top-Down (Consequent → Antecedent subgoals)
User Interaction Passive (user inputs all observations upfront) Active (system asks targeted questions to satisfy subgoals)
Canonical Applications Industrial monitoring, automated configuration (XCON) Medical diagnostic systems (MYCIN), theorem provers

5. Possible University Exam Questions & Marking Guide

NMIMS Pattern: 4, 6, 8, 10 Marks
4 Marks

Q1. Differentiate between Tautology, Satisfiable, and Unsatisfiable sentences in Propositional Logic with examples.

Marking Scheme: 1.5 marks for tautology and example; 1.5 marks for satisfiable; 1 mark for unsatisfiable.

Model Answer Key: Tautology is true under all interpretations (\(P \vee \neg P\)). Satisfiable has at least one true interpretation (\(P \wedge Q\)). Unsatisfiable/Contradiction is false under all interpretations (\(P \wedge \neg P\)).

6 Marks

Q2. Explain the Unification Algorithm in First-Order Logic. Give two examples of successful unifications and one failure case.

Marking Scheme: 2 marks for core concept/definition; 2 marks for successful unifications; 2 marks for failure case.

Model Answer Key: Unification finds variable substitution \(\theta\) such that \(\text{Subst}(\theta, p) = \text{Subst}(\theta, q)\). Give examples: \(\text{UNIFY}(\text{Knows}(\text{John}, x), \text{Knows}(\text{John}, \text{Jane})) = \{x / \text{Jane}\}\). Failure occurs when predicate names or arity differ, or during occur-check failure.

8 Marks

Q3. State the 10 production rules for the Water Jug Problem (4-gallon and 3-gallon jugs). Provide the exact step-by-step state transition table to obtain 2 gallons.

Marking Scheme: 4 marks for clearly listing all production rules; 4 marks for complete step-by-step transition table from \((0,0)\) to \((2,0)\).

Model Answer Key: Detail the 10 rules as presented in Section 1.5 and the exact 6-step operation sequence reaching state \((2, 0)\).

10 Marks

Q4. Explain the Resolution Refutation algorithm in First-Order Logic. Detail the five steps required to convert FOL sentences into Conjunctive Normal Form (CNF) with an illustrative example.

Marking Scheme: 3 marks for resolution principle and refutation strategy (\(\neg \alpha \to \square\)); 5 marks for 5 CNF conversion steps (implications, negations, standardization, skolemization, distribution); 2 marks for example resolution step.

Model Answer Key: Detail the refutation theorem proving concept. Explain the 5 conversion steps as listed in Section 1.7. Demonstrate clause cancellation via complementary literals.
