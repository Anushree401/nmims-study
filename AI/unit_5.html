1. In-depth theory explanation

Related: worked examples · comparative studies · case studies

1. Learning and induction

  • A program learns from experience E for tasks T and performance measure P if performance on T improves with E.
  • Inductive learning generalizes from examples to rules; it is uncertain because observed examples may not cover future cases.
  • Deduction applies a general rule to a case and, if premises/rule are true and inference valid, preserves truth.

3. Decision trees and split measures

  • A decision tree recursively partitions examples.
  • Internal nodes test features; branches encode outcomes; leaves predict class.
  • Training has two stages: construct model from labeled training set, then use it to classify unseen cases and evaluate on separate test data.
  • Attribute selection measures choose splits that make child nodes purer.
  • Entropy: H(S)=−Σᵢ pᵢ log₂ pᵢ.
  • Information gain: IG(S,A)=H(S)−Σᵥ |Sᵥ|/|S|·H(Sᵥ).
  • Gini impurity: Gini(S)=1−Σᵢ pᵢ².
  • Choose highest information gain or lowest weighted child impurity, depending on algorithm.

5. Overfitting and evaluation

  • A very deep tree can memorize noise: training accuracy is high while unseen-case accuracy is poor.
  • Controls include pre-pruning (maximum depth, minimum samples per split, minimum gain) and post-pruning (remove branches that do not improve validation performance).
  • Evaluate with a held-out test set or cross-validation; do not use test data to select the tree repeatedly.
  • The updated slide deck adds a student Pass/Fail illustration and recommends pruning, depth limits, minimum split size and ensembles.

6. K-means clustering

  • K-means is unsupervised partitioning for numeric feature vectors.
  • Given k, initialize centroids; assign each point to nearest centroid (usually Euclidean); recompute each centroid as mean of assigned points; repeat until assignments/centroids stop changing.
  • Objective: minimize within-cluster sum of squared distances (WCSS).
  • Feature scaling matters because large-scale features dominate Euclidean distance.
  • Initialization can lead to different local solutions; k must be chosen (e.g., domain needs/elbow/silhouette).

Simple example: one assignment step

  • Points A=(1,1), B=(2,1), C=(8,8), D=(9,8); initial centroids μ1=(1,1), μ2=(9,8).
  • Euclidean distance comparison assigns A,B→cluster 1 and C,D→cluster 2.

Medium example: centroid update

  1. Cluster 1 mean: ((1+2)/2,(1+1)/2)=(1.5,1).
  2. Cluster 2 mean: ((8+9)/2,(8+8)/2)=(8.5,8).
  3. Recompute all distances to these means; assignments remain unchanged, so algorithm converges.

Complex example: 1-D k-means full iterations

  • Data {1,2,3,10,11,12}, k=2; initialize μ1=2, μ2=10.
  1. Assign by nearest centroid: C1={1,2,3}; C2={10,11,12}.
  2. Update means: μ1=2; μ2=11.
  3. Reassign: same groups; means unchanged, terminate.
  4. WCSS = (1−2)²+(2−2)²+(3−2)² + (10−11)²+(11−11)²+(12−11)² = 1+0+1+1+0+1 = 4.
  5. Report k, initialization, assignment rule, centroid calculations, stopping condition and final objective.

Lesson A · What does it mean for a model to learn?

  • A learning system improves its performance from experience.
  • The classic definition names three parts: task T, experience E and performance measure P.
  • Example: predicting house prices (T), historical examples with features and sale prices (E), prediction error on unseen houses (P).
  • If training error falls but unseen error rises, the system has memorized examples rather than learned a useful pattern.
  • Induction generalizes from a finite sample to a rule that may apply to new cases; this is useful but uncertain.
  • Data quality, representative sampling, leakage and evaluation therefore matter.
  • Split data into training (fit parameters), validation (select settings) and test (final estimate); do not tune repeatedly on the test set.

Lesson B · Four learning paradigms through one analogy

  • Suppose an app must organize photographs.
  • In supervised learning, people label examples “cat,” “dog,” etc., and the model learns to predict those classes.
  • In unsupervised learning, no category labels are supplied; the algorithm groups images by similarity, and a human interprets what each group means.
  • In semi-supervised learning, a small labeled collection guides learning from a much larger unlabeled collection.
  • In reinforcement learning, an agent takes actions, observes rewards and learns a policy that maximizes long-term return.
  • These paradigms differ in feedback, not in whether an algorithm is “intelligent.” Supervised learning is not always better: labels may be costly or absent.
  • Unsupervised groups are not necessarily objectively correct.
  • Reinforcement learning requires careful reward design; optimizing a poor proxy can produce undesirable behavior.

Lesson C · Decision trees: from examples to test questions

  • A decision tree is a sequence of feature tests.
  • At a node the algorithm asks a question, partitions training cases by answer, and repeats.
  • Leaves predict the target class.
  • A shallow tree is easy to explain: “if attendance is high and study hours are high, predict pass.” A tree can model nonlinear rules because each branch creates a different region of feature space.
  • To select a split, measure class impurity.
  • Entropy is zero when a node has one class and maximal for a balanced binary mix.
  • Information gain is parent entropy minus the weighted child entropy.
  • Gini impurity is 1 minus the sum of squared class proportions; lower weighted child Gini is preferred.
  • Use the same class counts for every candidate feature so that gains are comparable.

Worked split with all arithmetic

  • There are 10 examples: 6 Pass, 4 Fail.
  • Attribute Attendance splits them into High: 4 Pass, 0 Fail; Low: 2 Pass, 4 Fail.
  1. Parent entropy = −(6/10)log₂(6/10)−(4/10)log₂(4/10)=0.971 bits.
  2. High entropy = 0 because all four cases are Pass.
  3. Low entropy = −(2/6)log₂(2/6)−(4/6)log₂(4/6)=0.918.
  4. Weighted post-split entropy = (4/10)(0)+(6/10)(0.918)=0.551.
  5. Information gain = 0.971−0.551=0.420 bits.
  6. Parent Gini =1−0.6²−0.4²=0.48. High Gini=0; Low Gini=1−(2/6)²−(4/6)²=0.444.
  7. Weighted child Gini=0.4(0)+0.6(0.444)=0.267; Gini reduction=0.48−0.267=0.213.
  8. Compute the same values for StudyHours and other candidate features. Choose highest IG or lowest weighted Gini, depending on criterion; then recursively split impure children.
  • Small rounding differences are acceptable.
  • Include the logarithm base, proportions, child weights and selection rule.

Lesson D · Generalization, overfitting and pruning

  • As a tree grows, it can create more specific rules.
  • Initially, added branches may capture real patterns and improve test performance.
  • Eventually branches may fit accidental quirks or mislabeled examples.
  • Then training accuracy remains high while test accuracy drops: overfitting.
  • Pre-pruning stops growth early using maximum depth, minimum samples per split or minimum gain.
  • Post-pruning grows a larger tree, then removes branches whose validation performance does not justify their complexity.
  • Ensembles such as random forests combine many trees and often improve generalization, at the cost of a less direct single-tree explanation.
  • In the supplied updated slides, a student Pass/Fail tree becomes overly specific; that illustration demonstrates memorization, not a guaranteed accuracy figure.

Lesson E · K-means by hand

  • K-means is for numeric feature vectors when a distance-based grouping is meaningful.
  • Each point belongs to exactly one of k clusters.
  • The algorithm alternates two operations: assignment (nearest centroid) and update (mean of assigned points).
  • Each operation does not increase the within-cluster sum of squared distances, so it converges to a local solution, but initialization can change which solution is reached.
  • Euclidean distance between (x₁,y₁) and (x₂,y₂) is √((x₁−x₂)²+(y₁−y₂)²).
  • For assignment, squared distance is enough because square root preserves ordering.
  • Standardize features when they have different units or scales; otherwise a feature measured in thousands can dominate one measured from 0 to 1.

2D worked example with actual distances

  • Points A=(1,1), B=(2,1), C=(8,8), D=(9,8); k=2; initial centroids μ₁=(1,1), μ₂=(9,8).
PointDistance to μ₁Distance to μ₂Assignment
A=(1,1)0√113 ≈ 10.63C1
B=(2,1)1√100 = 10C1
C=(8,8)√98 ≈ 9.901C2
D=(9,8)√113 ≈ 10.630C2
  1. Update μ₁: mean of A,B = ((1+2)/2,(1+1)/2)=(1.5,1).
  2. Update μ₂: mean of C,D = ((8+9)/2,(8+8)/2)=(8.5,8).
  3. Reassign points using new centroids; each point remains in its cluster.
  4. Recompute means; no change, so stop.
  5. WCSS = (0.5²+0²)+(0.5²+0²)+(−0.5²+0²)+(0.5²+0²)=1.0.

Complex 1D iteration

  • For {1,2,3,10,11,12}, k=2, initialize centers 2 and 10.
  • Assign {1,2,3} and {10,11,12}; update means to 2 and 11.
  • Assignments remain unchanged.
  • WCSS = (1−2)²+(2−2)²+(3−2)²+(10−11)²+(11−11)²+(12−11)²=4.
  • Report initialization because another initialization may yield a different local result.

FORMULA / RULE

  1. p(Pass)=5/5=1 and p(Fail)=0/5=0.
  2. H=−1log₂1−0log₂0=0.
  3. Gini=1−1²−0²=0.
FINAL ANSWER
Entropy=0 bits; Gini=0. See decision-tree split measures.

MEDIUM NUMERICAL Information gain for a two-way split

GIVEN
  • Parent set: 6 Yes, 4 No (10 examples).
  • Left child: 4 Yes, 0 No. Right child: 2 Yes, 4 No.
FORMULA / RULE
H(S)=−Σpᵢlog₂pᵢ; IG=H(parent)−Σ(|child|/|parent|)H(child).
STEPWISE WORKING
  1. Parent proportions are .6 and .4: H(parent)=−.6log₂.6−.4log₂.4≈0.971.
  2. Left child is pure: H(left)=0.
  3. Right proportions are 2/6 and 4/6: H(right)≈0.918.
  4. Weighted child entropy=(4/10)(0)+(6/10)(.918)=0.551.
  5. IG=.971−.551=0.420 bits.
FINAL ANSWER
This split gives 0.420 bits of information gain and reduces Gini by 0.213. Compare with other attributes. See tree construction.

GIVEN
  • Points: A=(1,1), B=(2,1), C=(8,8), D=(9,8).
  • k=2; initial centroids μ₁=(1,1), μ₂=(9,8).
FORMULA / RULE
Euclidean distance d=√((x−μₓ)²+(y−μᵧ)²); centroid = coordinate-wise mean; WCSS=Σ squared distances to assigned centroid.
STEPWISE WORKING
  1. Initial distances: A→(0,√113); B→(1,√98); C→(√98,1); D→(√113,0). The pair lists distances to μ₁, then μ₂.
  2. Assign nearest: C₁={A,B}; C₂={C,D}.
  3. Update μ₁=((1+2)/2,(1+1)/2)=(1.5,1).
  4. Update μ₂=((8+9)/2,(8+8)/2)=(8.5,8).
  5. Recompute assignments; each point remains in its cluster, so assignments have stabilized.
  6. Squared distance in each cluster: .25, .25, .25, .25.
  7. WCSS=.25+.25+.25+.25=1.

4. Case studies and real-life examples

Customer segmentation

  • A retailer can represent each customer by numeric purchase frequency and average spend, then use k-means to group similar profiles.
  • Cluster labels are discovered, not pre-known; a marketer must interpret them and validate that the groups are useful.
  • Scale features before Euclidean distance if units differ.
  • See k-means assignment and WCSS example.

Student pass/fail prediction

  • Study hours, attendance and assignment completion can be features, while Pass/Fail is the labeled target.
  • A decision tree creates interpretable rules.
  • A very deep tree may memorize a small class dataset; pruning and held-out evaluation test whether the rules generalize.
  • See overfitting and entropy calculation.

Lesson G · Numerical answer checklist

  • For entropy/Gini: state class counts, proportions, parent impurity, every child’s impurity, child weights, weighted impurity, gain/reduction, and which split wins.
