1.1 Foundations of Learning: What is Machine Learning?

In classical symbolic AI (as studied in Units 1 to 4), an agent is supplied with deterministic rules and explicit knowledge representations authored by domain experts. However, real-world problems often defy complete explicit formalization. Machine learning (ML) shifts the paradigm: instead of explicitly programming an agent with answers, we program it with a learning element that infers underlying mathematical mappings from empirical training data.

Formal Definition of Learning (Tom Mitchell, 1997)

"A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."

  • Task \(T\): E.g., classifying medical images or playing chess.
  • Experience \(E\): E.g., a database of historical X-ray records with labels or playing games against itself.
  • Performance Measure \(P\): E.g., diagnostic accuracy percentage or win-rate against human grandmasters.

Inductive Learning vs. Deductive Learning

Human intelligence and AI agents employ two fundamental modes of inference:

  • Deductive Learning (Top-Down): Infers specific logical consequences from generalized universal axioms. If the premises are true, the conclusion is guaranteed to be true (soundness). For example: $$\forall x \, (\text{Bird}(x) \implies \text{CanFly}(x)), \quad \text{Bird}(\text{Tweety}) \vdash \text{CanFly}(\text{Tweety})$$ Deductive reasoning preserves truth but generates no fundamentally new empirical hypothesis beyond what is already entailed.
  • Inductive Learning (Bottom-Up): Constructs a general hypothesis or mathematical function \(h\) from a finite collection of observed training examples \(\{(x_1, y_1), (x_2, y_2), \dots, (x_N, y_N)\}\). The fundamental assumption of inductive learning is: $$\text{Any hypothesis found to approximate the target function well over a sufficiently large set of training examples}$$ $$\text{will also approximate the target function well over unobserved test examples.}$$ Inductive reasoning generates powerful generalizable patterns, but its conclusions are probabilistic rather than logically infallible (e.g., observing 1,000 white swans induces the hypothesis that all swans are white, which is falsified upon seeing a black swan).

1.2 The Four Machine Learning Paradigms

Depending on the nature of feedback and the availability of ground-truth supervisor signals, machine learning algorithms are categorized into four distinct computational paradigms:

Figure 5.1: The taxonomy of Machine Learning paradigms based on training feedback and data structure.

Detailed Breakdown of Paradigms:

  1. Supervised Learning: The training dataset consists of input vectors paired with correct ground-truth supervisory labels: \(D = \{(x_i, y_i)\}_{i=1}^N\). The learner adjusts its parameters to minimize a loss function \(\mathcal{L}(y_i, h(x_i))\).
    • Classification: Target \(y\) belongs to a finite set of discrete category labels: \(y \in \{C_1, C_2, \dots, C_K\}\). Examples: Email spam detection (Spam / Not Spam), Disease diagnosis (Malignant / Benign). Algorithms: Decision Trees, Naive Bayes, Support Vector Machines (SVM), Logistic Regression.
    • Regression: Target \(y\) is a continuous real-valued number: \(y \in \mathbb{R}\). Examples: House price prediction, Stock valuation, Temperature forecasting. Algorithms: Linear Regression, Ridge/Lasso, Polynomial Regression.
  2. Unsupervised Learning: The training set contains only unlabeled feature vectors without any external ground truth or teacher: \(D = \{x_i\}_{i=1}^N\). The objective is to discover underlying structural properties, probability densities, or groupings:
    • Clustering: Grouping samples into distinct clusters such that intra-cluster similarity is maximized and inter-cluster similarity is minimized (e.g., K-Means, Hierarchical Clustering, DBSCAN).
    • Dimensionality Reduction / Feature Extraction: Projecting high-dimensional spaces to lower dimensions while preserving maximum variance (e.g., Principal Component Analysis - PCA).
    • Association Rule Mining: Discovering co-occurrence relationships (e.g., Market Basket Analysis: If Bread and Milk \(\implies\) Butter).
  3. Semi-Supervised Learning: In many real-world scenarios (e.g., medical imaging or speech analysis), collecting unlabeled data is cheap and abundant, but labeling requires expensive human domain experts. Semi-supervised learning utilizes a small seed of labeled data combined with a large pool of unlabeled data to construct higher-confidence decision boundaries.
  4. Reinforcement Learning (RL): An autonomous agent interacts dynamically with an uncertain environment modeled as a Markov Decision Process (MDP \(\langle S, A, P, R, \gamma angle\)). At each time step \(t\), the agent observes state \(s_t\), selects action \(a_t\), receives an immediate scalar feedback signal (positive reward or negative penalty \(r_{t+1}\)), and transitions to next state \(s_{t+1}\). The agent's goal is to learn an optimal policy \(\pi^*: S o A\) that maximizes expected cumulative discounted reward: $$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}, \quad \text{where } \gamma \in [0, 1] \text{ is the discount factor.}$$

1.3 Decision Tree Induction & Splitting Criteria

A Decision Tree is a hierarchical, non-parametric supervised learning model that represents decisions and their potential outcomes in an intuitive flowchart structure. It recursively partitions the input feature space into rectangular homogenous subsets.

Anatomy of a Decision Tree:

  • Root Node: The topmost node containing the complete dataset; it represents the first attribute test chosen via an Attribute Selection Measure (ASM).
  • Internal / Decision Nodes: Intermediate nodes that test a specific attribute condition (e.g., \(\text{Outlook} = \text{Sunny}\)). Branches outgoing from an internal node correspond to the distinct possible attribute values.
  • Leaf / Terminal Nodes: End nodes that hold no further split conditions. Each leaf node carries a final class decision label or regression value.

Figure 5.2: Decision Tree induced from the weather PlayGolf dataset.

The ID3 Algorithm & Attribute Selection Measures (ASM)

The standard top-down induction of decision trees (ID3 by Ross Quinlan) uses a greedy heuristic search: at each node, select the attribute that most effectively separates the classes into purest subsets.

1. Shannon Entropy (Measure of Impurity / Disorder):

Entropy \(E(S)\) quantifies the uncertainty or impurity in a sample set \(S\). If there are \(c\) distinct target classes with proportions \(p_1, p_2, \dots, p_c\):

$$\text{Entropy}(S) = - \sum_{i=1}^{c} p_i \log_2(p_i)$$
  • Pure Node: If all samples belong to the same class (e.g., \(p_1 = 1, p_2 = 0\)), then \(\text{Entropy}(S) = -1 \log_2(1) - 0 = 0\) (Minimum impurity).
  • Maximum Uncertainty: In a binary classification problem where samples are evenly split (\(p_+ = 0.5, p_- = 0.5\)): $$\text{Entropy}(S) = - (0.5 \log_2 0.5 + 0.5 \log_2 0.5) = - (0.5(-1) + 0.5(-1)) = 1.0 \text{ bit}$$
2. Information Gain (IG):

Information Gain represents the expected reduction in entropy achieved by partitioning the dataset \(S\) along the candidate attribute \(A\). If attribute \(A\) takes distinct values \(v \in \text{Values}(A)\), and \(S_v\) is the subset where \(A = v\):

$$\text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \text{Values}(A)} \frac{|S_v|}{|S|} \cdot \text{Entropy}(S_v)$$

The algorithm evaluates \(\text{Gain}(S, A)\) for all unused attributes and selects the attribute that maximizes \(\text{Gain}(S, A)\) as the splitting node.

3. Gini Index / Gini Impurity (Used in CART):

The CART (Classification and Regression Trees) algorithm uses the Gini Impurity rather than logarithmic entropy for computational speed:

$$\text{Gini}(S) = 1 - \sum_{i=1}^{c} p_i^2$$

For a binary split into subsets \(S_1\) and \(S_2\), the split Gini index is:

$$\text{Gini}_{\text{split}}(S, A) = \frac{|S_1|}{|S|} \text{Gini}(S_1) + \frac{|S_2|}{|S|} \text{Gini}(S_2)$$

The attribute with the lowest \(\text{Gini}_{\text{split}}\) is selected for the split.

1.4 Overfitting in Machine Learning & Mitigation Strategies

A central challenge in machine learning is ensuring that the model generalizes well to unseen real-world data rather than merely memorizing peculiarities of the training sample.

Definition of Overfitting

A hypothesis \(h \in H\) is said to overfit the training data if there exists an alternative hypothesis \(h' \in H\) such that \(h\) has smaller error than \(h'\) over the training data, but \(h'\) has a smaller error than \(h\) over the entire distribution of unseen test data:

$$\text{Error}_{\text{train}}(h) < \text{Error}_{\text{train}}(h') \quad \text{AND} \quad \text{Error}_{\text{test}}(h) > \text{Error}_{\text{test}}(h')$$

Root Causes of Overfitting:

  1. Noise and Outliers in Training Data: If the decision tree grows deep enough to isolate anomalous outliers into individual leaf nodes, it creates fractured, nonsensical decision boundaries.
  2. Small Training Sample Size: Coincidental correlations appear genuine when sample sizes are small (e.g., all 3 patients with attribute \(A\) happen to have disease \(B\) purely by chance).
  3. Excessive Model Complexity: A decision tree that grows until every leaf node has an entropy of 0 will produce 100% training accuracy but fail catastrophically on test data.

Figure 5.3: The Bias-Variance Tradeoff and Overfitting curve as model complexity increases.

Mitigation & Tree Pruning Techniques:

  • Pre-pruning (Early Stopping): Stop growing the tree before it perfectly classifies the training set. Halting criteria include:
    • Setting a maximum depth limit (max_depth).
    • Requiring a minimum number of samples to split an internal node (min_samples_split).
    • Halting if the information gain from the best split falls below a fixed threshold \(\epsilon\).
  • Post-pruning (Reduced Error Pruning): Allow the tree to grow to full depth (overfitting the data), and then prune subtrees bottom-up. For each non-leaf subtree, replace it with a single leaf node carrying the majority class label. If this replacement does not degrade performance on an independent validation dataset, the prune is kept permanently.
  • Ensemble Methods (Random Forests): Instead of relying on a single deep, high-variance decision tree, build an ensemble of hundreds of decorrelated trees using bootstrap aggregation (bagging) and random feature selection, averaging their votes to achieve low variance.

1.5 K-Means Clustering: Algorithm & Mathematics

K-Means is an iterative, distance-based partitioning algorithm for unsupervised learning. Given an unlabeled dataset \(X = \{x_1, x_2, \dots, x_N\} \subset \mathbb{R}^D\) and a user-specified hyperparameter \(K\) (the number of clusters), K-Means partitions the \(N\) observations into \(K\) disjoint clusters \(C = \{C_1, C_2, \dots, C_K\}\) such that each point belongs to the cluster with the nearest centroid.

The Objective Function (Inertia / WCSS):

K-Means seeks to find cluster assignments and centroids that minimize the Within-Cluster Sum of Squares (WCSS), also called Inertia:

$$J = \sum_{k=1}^{K} \sum_{x_i \in C_k} \| x_i - \mu_k \|^2$$

where \(\mu_k = \frac{1}{|C_k|} \sum_{x \in C_k} x\) is the mathematical mean (centroid) of cluster \(C_k\).

Figure 5.4: The iterative assign-and-update steps of the K-Means clustering algorithm.

The 4 Core Steps of K-Means:

  1. Step 1 (Initialization): Select \(K\) points from the dataset as the initial centroids \(\mu_1^{(0)}, \mu_2^{(0)}, \dots, \mu_K^{(0)}\) (e.g., via random selection or K-Means++ initialization).
  2. Step 2 (Assignment / Expectation Step): Assign each sample point \(x_i\) to its closest centroid using the Euclidean distance metric: $$C_k = \left\{ x_i : \| x_i - \mu_k \| \le \| x_i - \mu_j \| \quad \forall j \in \{1, \dots, K\} ight\}$$
  3. Step 3 (Update / Maximization Step): Recompute each centroid \(\mu_k\) by calculating the arithmetic mean of all data points assigned to cluster \(C_k\): $$\mu_k^{(t+1)} = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i$$
  4. Step 4 (Termination / Convergence Check): Repeat Steps 2 and 3 until a stopping criterion is met:
    • Centroid locations do not change: \(\|\mu_k^{(t+1)} - \mu_k^{(t)}\| \le \epsilon \quad \forall k\).
    • No sample changes cluster membership across iterations.
    • A maximum iteration limit is reached.

Distance Metrics in K-Means:

  • Euclidean Distance (\(L_2\) norm): The standard straight-line distance in Euclidean space: $$d(p, q) = \sqrt{\sum_{j=1}^D (p_j - q_j)^2}$$
  • Manhattan Distance (\(L_1\) norm / City Block): Sum of absolute coordinate differences (used in K-Medians): $$d(p, q) = \sum_{j=1}^D |p_j - q_j|$$

Cluster Quality Criteria:

  • High Intra-Class Similarity (Compactness): The distance between points within the same cluster should be minimal (low WCSS).
  • Low Inter-Class Similarity (Separation): The distance between distinct cluster centroids (Between-Cluster Sum of Squares, BCSS) should be maximal.

Simple Example

Problem 5.1: Shannon Entropy Calculation for Binary Target

Problem Statement: A small training dataset \(S\) for loan approval has 14 instances. Out of these, 9 applicants are approved (\(\text{Class} = \text{Yes}\)) and 5 applicants are rejected (\(\text{Class} = \text{No}\)). Calculate the Shannon Entropy \(\text{Entropy}(S)\) of this target distribution. (Note: \(\log_2 9 \approx 3.1699\), \(\log_2 5 \approx 2.3219\), \(\log_2 14 \approx 3.8074\)).

GIVEN

Total instances \(|S| = 14\).

Positive instances \(p_+ = \frac{9}{14} \approx 0.6429\).

Negative instances \(p_- = \frac{5}{14} \approx 0.3571\).

FORMULA
$$\text{Entropy}(S) = - p_+ \log_2(p_+) - p_- \log_2(p_-)$$
STEPS

Step 1: Compute logarithmic components using log quotient rules:

$$\log_2(p_+) = \log_2\left(\frac{9}{14} ight) = \log_2(9) - \log_2(14) = 3.1699 - 3.8074 = -0.6375$$ $$\log_2(p_-) = \log_2\left(\frac{5}{14} ight) = \log_2(5) - \log_2(14) = 2.3219 - 3.8074 = -1.4855$$

Step 2: Substitute probabilities and logs into the entropy equation:

$$\text{Entropy}(S) = - \left[ \frac{9}{14} \times (-0.6375) + \frac{5}{14} \times (-1.4855) ight]$$ $$\text{Entropy}(S) = - \left[ 0.6429 \times (-0.6375) + 0.3571 \times (-1.4855) ight]$$ $$\text{Entropy}(S) = - [ -0.4098 - 0.5305 ] = - [ -0.9403 ] = 0.9403 \text{ bits}$$
FINAL ANSWER

\(\mathbf{\text{Entropy}(S) = 0.940 \text{ bits}}\)

Interpretation: Since the data contains a mix of both classes (not purely 14/0 or 0/14), entropy is close to 1 bit, reflecting substantial uncertainty.

Medium Example

Problem 5.2: Attribute Selection & Information Gain for PlayGolf Root Node

Problem Statement: In the classic 14-sample weather dataset (\(|S| = 14\), with 9 \(\text{Yes}\) and 5 \(\text{No}\), hence \(\text{Entropy}(S) = 0.940\)), consider the candidate splitting attribute Windy, which has two categorical values: \(\text{Weak}\) and \(\text{Strong}\):

  • \(\text{Windy} = \text{Weak}\): 8 samples (6 \(\text{Yes}\), 2 \(\text{No}\))
  • \(\text{Windy} = \text{Strong}\): 6 samples (3 \(\text{Yes}\), 3 \(\text{No}\))

Calculate: (i) \(\text{Entropy}(S_{\text{Weak}})\), (ii) \(\text{Entropy}(S_{\text{Strong}})\), and (iii) the resulting \(\text{Gain}(S, \text{Windy})\).

GIVEN

\(|S| = 14\), \(\text{Entropy}(S) = 0.940\).

Subset \(S_{\text{Weak}}\): \(|S_{\text{Weak}}| = 8\), \(p_+ = \frac{6}{8} = 0.75\), \(p_- = \frac{2}{8} = 0.25\).

Subset \(S_{\text{Strong}}\): \(|S_{\text{Strong}}| = 6\), \(p_+ = \frac{3}{6} = 0.50\), \(p_- = \frac{3}{6} = 0.50\).

FORMULA
$$\text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \{\text{Weak}, \text{Strong}\}} \frac{|S_v|}{|S|} \text{Entropy}(S_v)$$
STEPS

Step 1: Compute \(\text{Entropy}(S_{\text{Weak}})\):

$$\text{Entropy}(S_{\text{Weak}}) = - [0.75 \log_2(0.75) + 0.25 \log_2(0.25)]$$

Note that \(\log_2(0.75) = -0.4150\) and \(\log_2(0.25) = -2.000\):

$$\text{Entropy}(S_{\text{Weak}}) = - [0.75(-0.4150) + 0.25(-2.000)] = - [-0.3113 - 0.5000] = 0.8113 \text{ bits}$$

Step 2: Compute \(\text{Entropy}(S_{\text{Strong}})\):

Since the classes are split perfectly 50-50 (\(p_+ = 0.5, p_- = 0.5\)):

$$\text{Entropy}(S_{\text{Strong}}) = - [0.5 \log_2(0.5) + 0.5 \log_2(0.5)] = - [0.5(-1) + 0.5(-1)] = 1.000 \text{ bit}$$

Step 3: Compute Expected Weighted Entropy of the split:

$$\text{Weighted Entropy} = \frac{8}{14} \text{Entropy}(S_{\text{Weak}}) + \frac{6}{14} \text{Entropy}(S_{\text{Strong}})$$ $$\text{Weighted Entropy} = \left(\frac{8}{14} \times 0.8113 ight) + \left(\frac{6}{14} \times 1.000 ight)$$ $$\text{Weighted Entropy} = 0.4636 + 0.4286 = 0.8922 \text{ bits}$$

Step 4: Compute Information Gain:

$$\text{Gain}(S, \text{Windy}) = 0.9403 - 0.8922 = 0.0481 \text{ bits}$$
FINAL ANSWER

\(\mathbf{\text{Gain}(S, \text{Windy}) = 0.048 \text{ bits}}\)

Exam Note: When compared against \(\text{Gain}(S, \text{Outlook}) = 0.246\) bits, Windy provides very low information gain and will therefore not be selected as the root node.

Complex Example

Problem 5.3: Complete Iterative 2D K-Means Clustering Trace

Problem Statement: Given four 2D data points in feature space: $$P_1 = (1, 1), \quad P_2 = (2, 1), \quad P_3 = (4, 3), \quad P_4 = (5, 4)$$ Perform K-Means clustering for \(K = 2\) clusters using Euclidean distance. Assume initial seed centroids are set to: $$\mu_1^{(0)} = P_1 = (1, 1), \quad \mu_2^{(0)} = P_2 = (2, 1)$$ Perform Iteration 1 and Iteration 2 until centroid convergence. Show all distance calculation tables and cluster reassignment steps explicitly.

GIVEN

Points: \(P_1(1,1), P_2(2,1), P_3(4,3), P_4(5,4)\).

Initial Centroids: \(\mu_1 = (1, 1), \mu_2 = (2, 1)\).

Distance Metric: \(d(P, \mu) = \sqrt{(x_P - x_\mu)^2 + (y_P - y_\mu)^2}\).

ITERATION 1

Step 1: Compute Euclidean distances from all points to initial centroids \(\mu_1(1,1)\) and \(\mu_2(2,1)\):

Point Coords \(d(P, \mu_1 = (1,1))\) \(d(P, \mu_2 = (2,1))\) Assigned Cluster
\(P_1\) \((1, 1)\) \(\sqrt{(1-1)^2 + (1-1)^2} = \mathbf{0.00}\) \(\sqrt{(1-2)^2 + (1-1)^2} = 1.00\) Cluster 1
\(P_2\) \((2, 1)\) \(\sqrt{(2-1)^2 + (1-1)^2} = 1.00\) \(\sqrt{(2-2)^2 + (1-1)^2} = \mathbf{0.00}\) Cluster 2
\(P_3\) \((4, 3)\) \(\sqrt{(4-1)^2 + (3-1)^2} = \sqrt{9+4} = \sqrt{13} \approx 3.61\) \(\sqrt{(4-2)^2 + (3-1)^2} = \sqrt{4+4} = \sqrt{8} \approx \mathbf{2.83}\) Cluster 2
\(P_4\) \((5, 4)\) \(\sqrt{(5-1)^2 + (4-1)^2} = \sqrt{16+9} = \sqrt{25} = 5.00\) \(\sqrt{(5-2)^2 + (4-1)^2} = \sqrt{9+9} = \sqrt{18} \approx \mathbf{4.24}\) Cluster 2

Step 2: Cluster Membership after Iteration 1:

$$C_1 = \{P_1\}, \quad C_2 = \{P_2, P_3, P_4\}$$

Step 3: Recompute Centroids \(\mu_1^{(1)}\) and \(\mu_2^{(1)}\):

$$\mu_1^{(1)} = P_1 = (1, 1)$$ $$\mu_2^{(1)} = \left(\frac{2 + 4 + 5}{3}, \frac{1 + 3 + 4}{3} ight) = \left(\frac{11}{3}, \frac{8}{3} ight) \approx (3.67, 2.67)$$
ITERATION 2

Step 4: Compute distances with updated centroids \(\mu_1(1, 1)\) and \(\mu_2(3.67, 2.67)\):

Point Coords \(d(P, \mu_1 = (1,1))\) \(d(P, \mu_2 = (3.67, 2.67))\) Assigned Cluster
\(P_1\) \((1, 1)\) \(\mathbf{0.00}\) \(\sqrt{(1-3.67)^2 + (1-2.67)^2} = \sqrt{7.13 + 2.79} \approx 3.15\) Cluster 1
\(P_2\) \((2, 1)\) \(\sqrt{(2-1)^2 + (1-1)^2} = \mathbf{1.00}\) \(\sqrt{(2-3.67)^2 + (1-2.67)^2} = \sqrt{2.79 + 2.79} \approx 2.36\) Cluster 1 (Migrated!)
\(P_3\) \((4, 3)\) \(\sqrt{(4-1)^2 + (3-1)^2} = \sqrt{13} \approx 3.61\) \(\sqrt{(4-3.67)^2 + (3-2.67)^2} = \sqrt{0.11 + 0.11} \approx \mathbf{0.47}\) Cluster 2
\(P_4\) \((5, 4)\) \(\sqrt{(5-1)^2 + (4-1)^2} = 5.00\) \(\sqrt{(5-3.67)^2 + (4-2.67)^2} = \sqrt{1.77 + 1.77} \approx \mathbf{1.88}\) Cluster 2

Step 5: Cluster Membership after Iteration 2:

$$C_1 = \{P_1, P_2\}, \quad C_2 = \{P_3, P_4\}$$

Notice that point \(P_2\) migrated from Cluster 2 to Cluster 1!

Step 6: Recompute Centroids \(\mu_1^{(2)}\) and \(\mu_2^{(2)}\):

$$\mu_1^{(2)} = \left(\frac{1 + 2}{2}, \frac{1 + 1}{2} ight) = (1.5, 1.0)$$ $$\mu_2^{(2)} = \left(\frac{4 + 5}{2}, \frac{3 + 4}{2} ight) = (4.5, 3.5)$$
CONVERGENCE

Convergence Verification (Iteration 3 Check):

  • For \(P_1(1,1)\): \(d(P_1, \mu_1) = 0.5 < d(P_1, \mu_2) = 4.30 \implies C_1\)
  • For \(P_2(2,1)\): \(d(P_2, \mu_1) = 0.5 < d(P_2, \mu_2) = 3.53 \implies C_1\)
  • For \(P_3(4,3)\): \(d(P_3, \mu_1) = 3.20 > d(P_3, \mu_2) = 0.71 \implies C_2\)
  • For \(P_4(5,4)\): \(d(P_4, \mu_1) = 4.61 > d(P_4, \mu_2) = 0.71 \implies C_2\)

No data point changes cluster assignment. Centroids remain identical: \(\mu_1^{(3)} = (1.5, 1.0)\), \(\mu_2^{(3)} = (4.5, 3.5)\). The algorithm has converged.

FINAL ANSWER

Final Cluster 1: \(\{P_1(1,1), P_2(2,1)\}\) with Centroid \(\mathbf{\mu_1 = (1.5, 1.0)}\)

Final Cluster 2: \(\{P_3(4,3), P_4(5,4)\}\) with Centroid \(\mathbf{\mu_2 = (4.5, 3.5)}\)

Supervised Learning Case Study

Credit Scoring & Loan Default Prediction (Banking & FinTech)

System Context: Commercial banks evaluate hundreds of thousands of personal loan applications daily. Loan approval officers use supervised Decision Tree ensembles (e.g., XGBoost, Random Forests) to predict the binary probability of borrower default (\(Y \in \{\text{Default}, \text{Non-Default}\}\)).

  • Feature Vector \(X\): Credit history score (CIBIL), debt-to-income ratio (DTI), annual income, employment tenure, requested loan amount, and existing revolving credit utilization.
  • Why Decision Trees? Explainability is a strict regulatory mandate (e.g., under FCRA and RBI fair lending directives). Black-box models (such as deep neural networks) cannot easily explain why an applicant was rejected. A Decision Tree provides a transparent decision path (e.g., "If Debt-to-Income > 45% and Credit Score < 650 \(\implies\) Reject"), enabling regulatory compliance and transparent adverse-action notifications.
Unsupervised Learning Case Study

E-Commerce Customer Segmentation (Retail & Marketing Analytics)

System Context: Online retail platforms like Amazon analyze transaction records of millions of users without manual labels to discover natural buying cohorts for hyper-targeted marketing campaigns.

  • Feature Space (RFM Model):
    • Recency (\(R\)): Days since last purchase.
    • Frequency (\(F\)): Total number of purchases in the last 12 months.
    • Monetary (\(M\)): Total revenue generated by the customer.
  • Clustering via K-Means: By running K-Means with \(K=4\) on normalized RFM vectors, the system automatically discovers:
    1. Champions / VIPs (Low R, High F, High M): Given exclusive loyalty rewards and early product access.
    2. At-Risk / Churning (High R, High F, High M): Targeted with aggressive re-engagement discounts.
    3. Promising Newbies (Low R, Low F, Medium M): Sent onboarding recommendations and nurture sequences.
    4. Lost Bargain Hunters (High R, Low F, Low M): Excluded from costly ad retargeting.

5. Possible University Exam Questions & Marking Guide

NMIMS Pattern: 4, 6, 8, 10 Marks
4 Marks

Q1. Differentiate between Inductive Learning and Deductive Learning with suitable examples.

Marking Scheme: 2 marks for core definitions/conceptual direction; 2 marks for clear domain examples.

Model Answer Key: Deductive learning works top-down from general axioms to specific conclusions without generating new hypotheses (\(\text{All humans are mortal} o \text{Socrates is human} o \text{Socrates is mortal}\)). Inductive learning works bottom-up, inferring generalized predictive models \(h(x)\) from finite specific training observations (\(\text{100 observed swans are white} o \text{Hypothesis: All swans are white}\)).

6 Marks

Q2. Explain the concept of Overfitting in Decision Trees. What are its causes, and how do pre-pruning and post-pruning mitigate it?

Marking Scheme: 2 marks for formal definition and bias-variance curve; 2 marks for causes (noise, small data, deep trees); 2 marks for pruning techniques.

Model Answer Key: Define overfitting: \(\text{Error}_{\text{train}}(h) < \text{Error}_{\text{train}}(h')\) but \(\text{Error}_{\text{test}}(h) > \text{Error}_{\text{test}}(h')\). Explain causes: capturing random noise, small sample size, unrestricted tree depth. Detail pre-pruning (stopping criteria like max_depth, min gain threshold) and post-pruning (reduced error pruning bottom-up on validation data).

8 Marks

Q3. Describe the K-Means clustering algorithm step-by-step. State its objective function, convergence conditions, and two limitations.

Marking Scheme: 2 marks for objective function (WCSS formula); 3 marks for 4 algorithmic steps (Init, Assign, Update, Repeat); 2 marks for convergence criteria; 1 mark for limitations.

Model Answer Key: State WCSS \(J = \sum_{k=1}^K \sum_{x_i \in C_k} \| x_i - \mu_k \|^2\). Detail 4 steps (initial centroid selection, Euclidean assignment, centroid recalculation via mean, convergence check). Convergence occurs when \(\Delta \mu = 0\) or assignments do not change. Limitations: Sensitive to initial seed selection (leads to local minima), requires specifying \(K\) in advance, struggles with non-spherical clusters and outliers.

10 Marks

Q4. (Comprehensive Numerical) In a classification dataset of 14 examples with 9 Yes and 5 No, compute Entropy(S). If an attribute 'Humidity' splits the set into 'High' (3 Yes, 4 No) and 'Normal' (6 Yes, 1 No), calculate Gain(S, Humidity) step-by-step.

Marking Scheme: 3 marks for \(\text{Entropy}(S) = 0.940\); 3 marks for \(\text{Entropy}(S_{\text{High}})\) and \(\text{Entropy}(S_{\text{Normal}})\); 4 marks for weighted sum and \(\text{Gain}(S, \text{Humidity})\) calculation.

Model Answer Key:

  • \(\text{Entropy}(S) = -\frac{9}{14}\log_2\frac{9}{14} - \frac{5}{14}\log_2\frac{5}{14} = 0.940\) bits.
  • \(\text{Entropy}(S_{\text{High}}) = -\frac{3}{7}\log_2\frac{3}{7} - \frac{4}{7}\log_2\frac{4}{7} = 0.985\) bits.
  • \(\text{Entropy}(S_{\text{Normal}}) = -\frac{6}{7}\log_2\frac{6}{7} - \frac{1}{7}\log_2\frac{1}{7} = 0.592\) bits.
  • \(\text{Weighted Entropy} = \frac{7}{14}(0.985) + \frac{7}{14}(0.592) = 0.4925 + 0.296 = 0.7885\) bits.
  • \(\text{Gain}(S, \text{Humidity}) = 0.940 - 0.7885 = 0.1515 \text{ bits}\).
