1. CPU scheduling: Gantt charts and metrics

Recognize: process table with arrival/burst/priority/quantum. First define whether policy is preemptive and tie rule. Draw time axis. At each decision, choose from ready jobs only; handle new arrivals before choosing at that instant as the prompt’s convention requires.

  1. Record each process’s first start and completion.
  2. Response = first start − arrival.
  3. Turnaround = completion − arrival.
  4. Waiting = turnaround − CPU burst (single-burst model with no extra service; otherwise sum ready-queue intervals).
  5. Average = sum / number of processes. Add units (ms, etc.).

FCFS uses arrival sequence; nonpreemptive SJF chooses shortest burst only when CPU becomes free; SRTF re-evaluates remaining burst at arrivals; priority requires high/low convention; RR expires at quantum and queues unfinished work at tail. Context-switch time is included only if stated.

2. Banker safety/request algorithm

Recognize: Allocation, Max, Available vectors/matrices, safety or request query. First compute Need=Max−Allocation. Compare componentwise.

  1. Safety: Work=Available, Finish=false.
  2. Find a process with Need≤Work; mark finish and add its Allocation to Work.
  3. Repeat; list safe sequence if all finish; otherwise no safe sequence is found.
  4. Request: validate Request≤Need and ≤Available. Pretend allocate; rerun safety; commit if safe, else roll back.

Units are resource instances, not time. Never compare summed totals when one resource component is deficient.

3. Page-replacement trace

Recognize: reference string and fixed frame count; asked for faults/replacements. Make a row per reference and one column per frame. A miss while empty increases faults but is not a replacement; a miss with full frames is both. FIFO tracks load age; LRU tracks most recent use; OPT looks forward.

For OPT, if future-use distances tie, any tied victim yields a valid fault count for that trace; say your tie choice. At the end, fault rate = faults / references if requested.

4. Disk head movement

Recognize: request queue, head start, scheduling policy. Show sequence including any endpoint or wrap. For each step compute |next−current| cylinders; sum. For SCAN/C-SCAN disk endpoints and initial direction are necessary. LOOK/C-LOOK use request extremes, not physical bounds. Do not label cylinder movement as seek time unless a timing model is provided.

6. Worked algorithm example: page replacement

Three frames; sequence 1,2,3,2,1,4; FIFO. 1,2,3 each fault and fill frames [1,2,3]. 2 and 1 hit. Reference 4 faults; evict oldest loaded page 1, giving [4,2,3]. Total=4 faults; 1 replacement (the first three faults were loads into empty frames). Rate=4/6=66.7%.

Why FIFO victim is 1: it entered before 2 and 3; recent use does not reset FIFO age.

7. Worked algorithm example: disk FCFS

Requests 70,140,50,125,30,25,160; head=60. FCFS path 60→70→140→50→125→30→25→160. Movements: 10+70+90+75+95+5+135=480 cylinders. Check every term is nonnegative absolute difference. No disk bounds are needed for FCFS.

Common errors and self-test

Self-test (answers follow)

For an arrival at 4, first run at 9, response time?

5 time units.

Need=(7,2), Work=(8,1): can process finish?

No; second component 2>1.

Does an initial page load count as a replacement?

No. It is a fault, but there was no victim to replace.

Disk path 10→4→13 has total movement?

|4−10|+|13−4|=6+9=15 cylinders.

What should you do if disk direction is unspecified for SCAN?

State the assumption explicitly or report both possible paths if the outcome depends on direction.

5.5 Dynamic storage allocation numericals

Recognize: ordered hole list and ordered requests; simulate each policy sequentially and update leftover hole sizes.

For holes 100,500,200,300,600 K and requests 212,417,112,426 K: first-fit serves 212 from 500 (288 left), 417 from 600 (183 left), 112 from the 288 remainder (176 left), then cannot place 426. Best-fit serves requests from 300 (88 left), 500 (83 left), 200 (88 left), and 600 (174 left). Worst-fit serves 212 from 600 (388 left), 417 from 500 (83 left), 112 from 388 (276 left), then cannot place 426. The result depends on order; record holes after every allocation.

5.6 Address translation, TLB, and timing calculations

Paging: page p=⌊A/S⌋, offset d=A mod S. Look up frame f; physical address=fS+d. Verify 0≤d<S.

Segmentation: for logical <s,d>, ensure segment s exists and d<limit[s]; physical=base[s]+d.

TLB effective access time: if m=10 ns and hit ratio h=.80, with zero lookup overhead, EAT=.8(10)+.2(20)=12 ns. At h=.99, EAT=10.1 ns. Check that miss path includes page-table access and data access.

Swapping transfer: time=size/rate. For 100 MB at 50 MB/s, one-way=2 s; swap out plus swap in=4 s, excluding overhead.

What to know for the exam

Be ready to define the central terms, compare mechanisms using their assumptions and trade-offs, trace a process or algorithm step by step, and justify the result. State units and conventions whenever a question supplies them.
