1. File abstraction and metadata

A file is a named logical collection with creator-defined contents, often viewed as a contiguous logical address space. Types may be text, source, executable, numeric, character, binary, or structured. Attributes include name, unique identifier, type, location, size, protection, timestamps, and owner/user information; directory structures store this metadata.

Operations: create, open, read, write, reposition/seek, close, delete, truncate. Open-file tables track active files; each process may have a file pointer and access rights, while a system-wide entry tracks location/open count.

2. Access methods and file organization

Sequential access reads/writes the next record and supports reset; direct access addresses fixed-length logical records by relative block number n (read n, write n, position n, rewrite n). File structure may be byte/word sequence, lines/fixed or variable records, or complex formatted structures. The OS or application may interpret the structure.

3. Directories and volumes

Directory operations include search, create/delete, list, rename, traverse. A single-level directory is simple but has name collisions and no grouping. Two-level directories give each user a directory and permit same filenames for different users, but limited grouping. Tree directories support hierarchy/pathnames. Acyclic-graph directories permit shared files/subdirectories without cycles.

A disk can have partitions; a formatted partition/volume contains a file system and directory metadata. Raw partitions lack a general-purpose file system. General-purpose and special-purpose file systems can coexist.

4. Sharing and protection

Multi-user sharing requires identities and permissions. User IDs and group IDs help assign owner/group rights. File locks can be shared (multiple readers) or exclusive (writer); mandatory locking denies conflicting access, advisory locking lets programs inspect and cooperate. Remote file systems use networked client-server access; standard file calls can be translated to remote requests. Slides mention NFS, CIFS, FTP, web access, and distributed naming services.

Recap and self-test

Self-test (answers follow)

Sequential versus direct access?

Sequential processes next records in order; direct access names a relative record/block.

Why have an open-file table?

To track open files and data needed to manage access, pointers, counts, rights, and location.

What does an acyclic graph add over a tree?

Sharing of files/subdirectories while prohibiting cycles.

Mandatory versus advisory lock?

Mandatory lock enforcement denies conflicting access; advisory locking relies on programs to check/cooperate.

What is a volume?

An entity containing a file system.
